# iOS 1:1 이식 격차표 (2026-09-14, 오케스트레이터 판정)

기준: `android-inventory-layouts.md`(106), `android-inventory-smart-input.md`(60), `android-inventory-ui-theme-settings.md`(약 460). iOS 현재 코드는 `ios/`(스파이크: 두벌식 키면 + 조합기 + 온보딩 체크리스트).

상태 표기
- `없음` — iOS에 아직 없음. 이식 대상.
- `부분` — 일부만 있음.
- `있음` — 동등 기능 있음.
- `비해당` — iOS 플랫폼에 대응물이 없거나 정책상 불가. 이유를 적음.
- `1차 밖` — 잠긴 설계(D1~D8, P1~P5)로 1차 릴리스 범위 밖.

원칙: 모바일 표면(천지인·나랏글·베가·단모음·모아키)은 Android처럼 **두벌식 키 토큰으로 변환해 조합기에 넣는다**(`MobileHangulComposer.kt:387`). iOS 조합기는 두벌식 하나만 알면 된다. 세벌식 6종은 전각 그리드(13열)가 필요하므로 아이폰 폭에서는 키 최소 44pt를 지키는 별도 그리드 설계가 필요하다.

## 5. 정직하게 적는 한계

- 햅틱·키 소리는 iOS 확장 제약으로 Android와 같게 만들 수 없다(FA 없이 햅틱 불가, 볼륨 조절 불가).
- 클립보드·음성·앱별 프로필·인라인 제안·버퍼 붙여넣기는 플랫폼 비해당이다. 1:1이 아니라 "동등 목적의 iOS 방식"으로 바꿔야 한다.
- 세벌식은 아이폰 폭에서 13열을 44pt로 못 넣는다. 가로 모드 전용 또는 2층 시프트 설계가 필요하다(설계 결정 대기).
- 위키 "17종 자판"은 코드와 다르다(엔진 9 + 모바일 표면 9). 위키를 고쳐야 한다.
