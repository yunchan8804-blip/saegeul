# AI 금고 몰입 설계 — 레벨 곡선·스트릭·언락

> 조사 기준일: 2026-09-11
> 상태: 설계 확정 (레벨 곡선 구현 완료, 스트릭·언락은 후속 구현)
> 배경: 키보드(IME) 표면에는 광고를 달 수 없으므로(`docs/business/ad-monetization-avenue-operations.md` 13.1), 사용자가 앱을 **자주 열고 싶게** 만들어 앱 표면(대시보드·테마 상점)에서 수익화한다.

## 1. 조사 근거 요약

- 스트릭은 효과가 입증됐다. Duolingo A/B: 일일 목표와 스트릭 분리 시 D14 리텐션 +3.3%, 7일+ 스트릭 보유자의 다음 날 재사용 확률 2.4배([Duolingo 블로그](https://blog.duolingo.com/improving-the-streak/)).
- 스트릭 프리즈는 장기 리텐션을 높인다(장기 리텐션 약 10%↑, 프리즈 사용자 평균 스트릭 17.19일 vs 11.62일 — [Trophy 케이스 스터디](https://trophy.so/blog/duolingo-gamification-case-study)). 프리즈는 **자동 적용 + 상한(기본 2개)**이 원칙이다. 구매식은 실패 시점에 앱을 안 연 유저에게 닿지 않는다.
- 어려운 업적일수록 리텐션이 높다(난이도별 14일 리텐션 32%→74% 단조 증가, 같은 출처).
- 맥스 레벨에 너무 빨리 도달하면 목표 상실 이탈이 일어난다(Duolingo 25레벨 이후 동기 상실 사례 다수). 곡선은 비선형(초반 완만, 후반 가파름)이어야 한다.
- 과도한 게이미피케이션은 역효과다. 기대된 외적 보상은 내적 동기를 잠식한다(overjustification, [Lepper et al. 1973](https://en.wikipedia.org/wiki/Overjustification_effect)). 단절 스트릭을 노출하는 것은 추적하지 않는 것보다 나쁘다([JCR 2022](https://academic.oup.com/jcr/article-abstract/49/6/1095/6623414)).

## 2. 레벨 곡선 (구현 완료)

`input/ai/TypingDnaLevelCurve.kt` — 분석 문장 수 기준.

- **1~5레벨은 기존 경계(15/45/100/200) 보존**: 기존 사용자 레벨이 절대 내려가지 않는다.
- **6레벨부터 지수 곡선**: `threshold(L) = ceil(31.9 × (L−1)^1.3232)`로, 말렙 2500의 요구치가 누적 약 100만 문장(하루 200문장 기준 약 10년+)이 되도록 피팅했다. 말렙이 며칠 만에 닿으면 목표가 사라진다.
- 등급 타이틀: 마스터(5) → 장인(6~9) → 대가(10~24) → 현자(25~99) → 전설(100~249) → 신화(250~999) → 항성(1000~2499) → 우주(2500).
- 레벨 보너스: 25/100/1000레벨부터 광고 적립 +1/+2/+3점(포인트 경제와 연결).
- 테스트: `TypingDnaLevelCurveTest` — 임계 보존, 단조성, 말렙 규모, 진행률 경계.

## 3. 스트릭 (설계 확정, 구현 대기)

- **정의**: 하루 1문장 이상 분석(=키보드 학습 1건)이면 스트릭 유지. 일일 진입장벽은 최저로.
- **저장**: 온디바이스(`SharedPreferences`), 마지막 활동 일·현재 스트릭·프리즈 잔여 개수.
- **프리즈**: 기본 2개 자동 지급, 하루 건너뛰면 자동 소진. 재보급은 7일 스트릭 달성 시 1개. 프리즈를 안 쓴 날은 "완전 스트릭"으로 별도 표기.
- **표시**: 대시보드 상단과 학습 카드에 스트릭 숫자 노출. 단, **절단된 스트릭(0이 된 뒤의 "연장하세요" 압박)을 노출하지 않는다**. 스트릭이 끊겼으면 조용히 0에서 다시 시작한다(JCR 2022 근거).
- **마일스톤**: 7/30/100/365/1000일에 기념 배지 + 포인트 보너스(7일=5점, 30일=15점, 100일=50점, 365일=150점, 1000일=400점).

## 4. 레벨별 언락 (설계 방향)

원칙: 핵심 기능은 절대 잠그지 않고, **외장재와 편의·표현**만 언락한다. 어려운 업적일수록 리텐션이 좋다는 근거에 따라 상위 구간에 희소한 보상을 둔다.

| 구간 | 언락 |
|---|---|
| 5 | 대시보드 상세 차트 확장 |
| 10 | 테마 상점 포인트 적립 보너스 +1 |
| 25 | 금고 배지 프레임 1종 |
| 50 | 스트릭 프리즈 최대치 3개 |
| 100 | 전용 테마 1종 무료 지급 + 적립 보너스 +1 |
| 250 | 금고 위젯 테마 확장 |
| 1000 | 적립 보너스 +2, 희소 배지 |

## 5. 레벨업 보상과 축하 이펙트 (2026-09-12 구현)

- **레벨업당 포인트 +10점**(`PointPricing.POINTS_PER_LEVEL_UP`). 학습이 반영되어 레벨이 오르는 시점에 원장에 기록(`EARN · level-up`)되고 "축하 대기" 플래그가 설정된다. 여러 레벨을 한 번에 오르면 레벨 수만큼 합산 지급된다.
- 기존 유저의 첫 실행은 현재 레벨을 기준선으로 기록만 하고 소급 지급하지 않는다.
- **앱 진입 축하 이펙트**: 대기 플래그가 있으면 대시보드 진입 시 컨페티 오버레이(`CelebrationOverlayView`, 3초 1회 재생 후 자동 제거) + 축하 다이얼로그. 재생 뒤 플래그는 즉시 해제된다.
- **위젯 글로우**: 대기 플래그가 있는 동안 위젯은 글로우 테두리 + "🎉 Lv.N 달성! 탭해서 확인"으로 바뀌고, 탭해 대시보드에서 조회하면 플래그가 해제되며 다음 갱신 때 일반 위젯으로 돌아온다.
- 포인트 잔액은 메인 금고 카드와 대시보드 레벨 카드에 "💎 포인트 N점"으로 상시 표시된다.
- 레벨 보상은 상위 레벨일수록 적립 보너스와 함께 누적되므로, 레벨 2500까지의 총 지급량도 외장재 가격 대비 과도하지 않게 테마 가격으로 균형을 잡는다.

## 6. 실험 원칙

- 스트릭·언락 도입도 홀드아웃 비교로 검증한다(광고 파일럿과 동일 게이트).
- 효과는 신기 효과로 4주 내외 감소한다([Rodrigues et al. 2022](https://link.springer.com/article/10.1186/s41239-021-00314-6)). 분기마다 마일스톤·배지 콘텐츠를 보충한다.
- 경쟁 리더보드는 도입하지 않는다. 사회적 비교 피로가 이탈 경로로 확인됐고, 키보드 사용량은 민감한 행동 데이터라 공개 자체가 개인정보 경계와 충돌한다.
