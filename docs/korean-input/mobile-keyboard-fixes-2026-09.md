# 모바일·세벌식 자판 수정 설계 (2026-09-27)

전수 감사(자판 9종 화면 자판 + libhangul 배열 9종)에서 나온 문제와 확정한 수정 방향이다. 코드가 이 문서와 다르면 이 문서를 먼저 고친다.

## 조합기(`MobileHangulComposer`) 계약

- **버퍼 일치**: 조합기가 보낸 키를 libhangul 두벌식이 그대로 받았을 때, 버퍼는 항상 "순환 시작 전 글" + `result(P, 선택 자모)`와 같아야 한다. `P`는 순환 시작 때의 앞 모음이다. `result`는 `P`와 선택 자모가 합쳐지면 합친 모음이 `P`를 대신하고, 안 합쳐지면 `P` 뒤에 선택 자모가 붙는다.
- **교체 시 지우기**: 순환 교체는 "이번 순환이 시작된 뒤 보낸 두벌식 키 수"만큼만 Backspace를 보낸다. 앞 모음을 지웠다면 다시 보낸다. (K3: 베가 ㅣㅡ 키는 ㅣ→ㅡ→ㅢ 3단 순환이다. `구` + 이 키 1번은 `귀`, 2번은 `구ㅡ`, 3번은 `구ㅢ`, 4번은 `구ㅣ`이며, 앞 모음이 지워져 `그`가 되면 안 된다.)
- **엔진 확정 뒤에는 앞 모음을 놓아준다**: 순환 중 선택 자모가 앞 모음 `P`와 합쳐지지 않으면 libhangul은 `P`가 든 글자를 에디터로 확정한다. 확정된 글자는 키 단위로 지울 수 없으므로(Backspace가 글자 전체를 지운다), 그 뒤로는 이번 순환에서 `P`와 다시 합치지 않고 선택 자모만 바꾼다. 교체 때 지우는 키 수는 아직 조합 중인(preedit) 키만 센다.
- **조합기 상태는 키 동작 순서에 흔들리지 않는다**: 키를 뗄 때 오는 부수 동작(백스페이스 키의 선택 삭제 `DeleteSelectionAction`, 커서 이동 `MoveSelectionAction`)은 조합기를 초기화하지 않는다. 실제 선택·커서 변경은 K2의 선택 변경 신호로 초기화된다.
- **겹받침을 만드는 자음 교체(K21)**: 순환 키(천지인 ㅅㅎ·ㄷㅌ·ㅇㅁ, 베가 ㅁㅅ 등)나 획추가·쌍자음 변환으로 자음을 바꿀 때, 첫 선택 자음이 앞 글자의 받침과 겹받침을 이루지 못하면 libhangul은 앞 글자를 에디터로 확정한다. 이후 교체된 자음이 앞 글자의 받침과 겹받침을 이룰 수 있으면(예: 받침 ㄴ + ㅎ = ㄶ, ㅂ + ㅅ = ㅄ, ㄹ + ㅌ = ㄾ, ㄴ + ㅈ = ㄵ), 조합기는 조합 중인 키를 지운 뒤 Backspace 한 번을 더 보내 확정된 앞 글자를 지우고, 앞 글자를 자모로 풀어 두벌식 키로 다시 친 다음 새 자음을 보낸다(`만` + ㅅ → `만ㅅ`, 교체 → `많`). 앞 글자는 키보드가 받는 조합 중 글자(preedit) 신호로 알고, 겹받침 가능 여부는 두벌식 겹받침 표로 판단한다. 반대로 겹받침에서 겹받침이 안 되는 자음으로 바뀌면(ㄶ → ㅆ) libhangul이 자연스럽게 처리하므로 추가 동작은 없다.
- **검증 기준**: 조합기 테스트는 libhangul 두벌식처럼 글자 확정을 흉내 내는 시뮬레이터(조합 중 키는 키 단위로 지우고, 확정된 글자는 Backspace 한 번에 한 글자씩 지움)로 최종 글을 확인한다.
- **ㆍ 대기 중 Backspace**: ㆍ가 대기 중(`pendingDots > 0`)일 때 Backspace는 대기 개수만 하나 줄이고 엔진에 Backspace를 보내지 않는다. (K1)
- **스페이스 끊기**: 제한 시간 안의 스페이스를 "순환 끊기"로 먹는 규칙은 **천지인식 자음 순환**(제한 시간이 `PHONEPAD_MULTITAP_TIMEOUT_MS` 이상이고 마지막 선택이 자음)에만 적용한다. 모음 순환과 단모음(300ms)의 스페이스는 항상 공백이다. (K4)
- **ㅣ 결합표는 자판별**: `ㅠ + ㅣ → ㅝ`는 천지인 계열(ㆍ로 ㅠ를 만드는 자판)에서만 쓴다. 나랏글·단모음·모아키에서는 ㅠ 뒤의 ㅣ가 새 모음이다. 조합기는 생성 시 자판 계열을 받는다. (K10)
- **획추가**: 나랏글 획추가에 `ㅐ→ㅒ`, `ㅔ→ㅖ`를 더한다. (K12)
- **초기화 시점**: 입력칸이 바뀔 때(`onStartInput`), 조합 중인 글자(preedit)가 비어 있는 상태의 선택 영역 변경(후보 선택, 커서 이동, 외부 편집), 모바일이 아닌 키 입력 때 조합기 상태를 초기화한다. (K2)

## 자판 배열·표시

| # | 대상 | 결정 |
|---|---|---|
| K5 | `.,` `?!` `?.!` 라벨 키 | 누를 때마다 기호가 바뀌는 순환 키. 순서: `.,`→`. ,`, `?!`→`? !`, `?.!`→`. ? !`. 첫 입력은 지금과 같다. 제한 시간은 그 자판의 순환 시간 |
| K13 | 베가·나랏글(중앙 아님)의 `,` 키 | 라벨 `.,?!`, 순환 `. , ? !` |
| K6 | 모바일 자판의 🌐 | `showLangSwitchKey` 설정을 따른다(TextKeyboard와 동일) |
| K7 | 세벌식 5종·안마태 Caps Lock | 화면 라벨은 엔진이 실제로 넣는 자모와 같아야 한다. Shift 자모 라벨은 한 번 Shift(Once)일 때만 |
| K8 | 세벌식 5종·안마태 누름 미리보기 | 라틴 문자가 아니라 그 키의 한글 자모를 보여 준다(TextKeyboard의 `onPopupAction` 방식) |
| K9 | 한손 모아키 | 모음 키의 ㅣ·ㅡ 밀기는 천지인 `VowelI`·`VowelEu` 의미(앞 모음과 결합)로 보낸다. 그래서 ㅑ+ㅣ→ㅒ, ㅕ+ㅣ→ㅖ가 된다. 양손 모아키의 ㅡ 키도 `VowelEu` |
| K14 | 폴드 분할 모드 | 모바일 화면 자판(천지인 계열·베가·나랏글·단모음·모아키)은 분할하지 않고 한 덩어리로 가운데 배치한다 |
| K15 | 숫자행 고정 + 5행 자판 | 높이 보정을 `(행 수 + 1) / 행 수`로 계산한다 |
| K16 | 모아키 제스처 기준 거리 | px 고정값 28 대신 dp 기준값을 쓴다 |
| K19 | 천지인 ㆍ 대기 표시 | ㆍ가 대기 중이면 ㆍ 키 글자색을 강조색으로 바꾸고, 2개면 라벨을 `‥`로 바꾼다. 에디터 글에는 넣지 않는다 |
| K20 | 넓은 화면(폴드 펼침 등)의 전화 키패드형 자판 | 천지인 계열·베가·나랏글·단모음·모아키는 화면 폭이 600dp를 넘으면 자판 폭을 480dp로 제한하고 가운데 둔다(폴드6 펼침에서 천지인이 1,856px 전체로 늘어나 키 간격이 너무 넓었다). 두벌식 등 QWERTY형은 기존 분할·폭 규칙 그대로 |

## 이번에 하지 않는 것

- 나랏글 ㅜ 뒤 ㅏㅓ 키 반복(ㅝ에서 멈춤), 나랏글 ㅋㅌㅍㅊㅎ 되돌림 순환: 따를 명세가 없다.
- 자판 사이 편집 키(⌫·↵·스페이스) 위치 통일: 삼성 배열을 따른 의도된 배치다.
