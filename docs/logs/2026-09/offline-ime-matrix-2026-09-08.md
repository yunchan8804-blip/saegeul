# 오프라인 실기기 문장 추천 점검

## 범위와 판정 계약

유선 A35(`RFCX60GBL3D`)의 실제 새글 IME와 전송 기능이 없는 테스트 입력창에서 24개 합성 문맥을 확인한다. AI 네트워크를 끄고 종료 시 원래 설정으로 복원한다. 기존 개인 금고를 비우거나 열람하지 않는다. 현재 설치팩 개수를 함께 기록하며, 선택팩이 설치된 결과를 기본팩만의 성능으로 주장하지 않는다.

관측은 후보 조회, 최종 문장 후보, 실제 화면 표시, 선택 후 정확히 한 번 삽입을 구분한다. 최초 비동기 빈 snapshot을 곧바로 최종 빈 결과로 기록하지 않는다. 관측 대기시간은 키 입력 지연 측정값으로 해석하지 않는다. 개인 후보는 개수와 source만 기록하고 내용은 기록하지 않는다. 문장팩 후보만 합성 문맥과 결합해 의미·조사·어미·띄어쓰기·말투를 루트가 직접 평가한다.

빈 후보는 제공률의 한계로 남긴다. 후보 클릭 실패·중복 삽입·원문 훼손은 기능 결함으로 처리한다. 후보가 생성됐다는 이유만으로 자연스러움이나 모든 앱의 동작을 통과로 보지 않는다. 실제 한글 키를 한 타씩 누르는 조합 경로와 IME를 통한 합성 문맥 주입은 구분한다.

## 실행 결과

## 수정과 재검증

루트는 약한 결과 혼입을 반려했다. 두 팩의 결과에서 가장 긴 문맥 일치와 가장 강한 근거 집합만 유지하도록 병합 계약을 바꿨다. LAST_WORD 한 어절 근거에서만 후속 끝의 `.?!`를 요구해 명확히 불완결인 조각을 제외한다. 강한 prefix·두 어절 이상 근거의 무구두점 질문은 보존한다. 이는 형태소·의미 검증기가 아니며 일반 말투·문법 적합성을 보장하지 않는다.

첫 실행의 클릭은 정상 입력 경로를 타므로 개인 학습 상태에 영향을 줄 수 있다. 재검증은 가로 스크롤 대상 case3과 새 합성 문맥 `저는 지금 `, `혹시 내일 시간 `을 사용하며, 기존24와 같은 조건의 개선율이라고 주장하지 않는다. 기존 개인 기록은 삭제하지 않는다. 최초 표시와 스크롤 후 표시를 별도 기록하고, 다른 화면을 임의로 스크롤하지 않는다.

품질 수정은 관련 단위39건(failure/error/skip0) 통과. 기기 새 문맥 `저는 지금 ` → `생각난 내용을 메모해 둘게요.`, `혹시 내일 시간 ` → `괜찮으면 같이 점심 먹자.`가 각각 표시·선택·한 번 삽입을 통과했다(`matrix-quality-case25.log`, `26.log`, 대응 PNG). case25의 두 번째 `어디쯤인지 알려줄 수 있어?`는 첫 사람 주어·정중 말투와의 연결이 여전히 미흡해 일반 문맥 품질 완료로 보지 않는다.

case3은 실제 후보 행에 가로 scroll action을 두 번 수행해도 실패했다(`matrix-case3-scroll.log`). 로컬 Flexbox3.0.0 bytecode 조사에서 기본 생성자의 `FlexWrap.WRAP`과 NOWRAP 지원을 확인했다. 단어 행은 NOWRAP을 명시하지만 문장 행은 기본 WRAP이고 높이가30dp·세로 scroll불가여서, 두 번째 문장이 다음 줄로 배치되면 접근할 수 없는 구조였다. 루트가 문장 layout manager에 NOWRAP을 지정했다. 동일case 재검증(`matrix-case3-nowrap.log`)은 initialUiSuffixPresent=true, scrollAttempts=0, clickInsertionMatched=true, OK1건으로 통과했다. 긴 후보의 일부가 가로 화면 경계에 걸릴 수는 있으며, 전체 문장을 한 화면에 모두 표시했다고 주장하지 않는다. 대응 후보 crop도 루트가 확인했다.

## 최종 아티팩트와 남은 문제

최신 app SHA-256 `6F16C6C211D8D11E0A49D40442DDDB14AAA36766363164704DE515C338DF3B70`, 66,871,717bytes. A35 업데이트 설치 및 표시 결함 회귀를 확인했다. `saegeul-debug-device-audit-fix-20260908.apk`를 20:33:59 폴드6 Taildrop으로 전송했다(`taildrop-device-audit-fix.log`). 폴드6 설치·실행은 미확인이다. 커밋·push·서브모듈 변경은 하지 않았다.

워커의 초기 준비조건·UI helper 누락은 반려 후 수정했고, 루트가 실제 diff·로그·후보 이미지를 평가했다. 품질 수정 단위39건, 신규 문맥 기기2건, 동일 표시 회귀1건은 서로 다른 검증이다. 첫24 matrix 실패를 최종 전체24통과로 바꾸지 않는다.

남은 품질 과제는 자유로운 미완성 입력의 제공 범위, 첫 사람 주어와 후속 문장의 일치, 반말·존댓말 일관성이다. 다음 검증은 기본팩만·빈 금고 환경을 별도로 준비해 진행해야 하며 현재 개인 데이터는 보존한다. 이번 테스트는 실제 IME에서 합성 문맥을 입력했지만 한글 자판을 음절별로 눌러 조합하는 전 과정을 검증한 것은 아니다.
