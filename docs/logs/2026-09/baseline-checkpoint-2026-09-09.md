# Gemma 실험 전 기준 상태

- 기존 입력·금고·문장팩·컴패니언 변경과 운영 도구를 보존한다. 실기기 원본 로그·화면·빌드 산출물은 `.artifacts/`에 유지하고 Git 추적에서 제외한다.
- Android 전체 단위 테스트: 1,111건, 실패 0, 오류 0, 기존 스킵 7. `:app:testDebugUnitTest -PbuildABI=arm64-v8a`, JDK 17. 원문: `.artifacts/gemma-experiment-20260909/baseline-final-unit.log`.
- 컴패니언: `python scripts/test_ai_provider_companion.py`, 28건 통과. 샌드박스 임시 디렉터리 권한 실패 후 허용된 환경에서 재검증했다.
- 최초 전체 검사 실패 3건은 보존했다. 한국어 조사가 붙은 전화번호를 놓치는 숫자 경계를 수정했다. 빈 저장소에서 근거 없이 문장을 요구하던 테스트는 명시적인 저장 재료와 정확한 결과를 검증하도록 수정하고, 빈 저장소의 추천 0건 회귀를 추가했다.
- 한글 엔진 포크 `317a9f8`에 기존 다음 어절 사전 확장과 비한글 후보 제거를 보존했다. 483개 항목, 27,129바이트, parser의 완성형 한글·용량·항목 수 조건을 확인했다. Windows C/C++ 컴파일러가 PATH에 없어 별도 CMake 실행 검증은 미완료다. 수정 전 원본은 서브모듈 stash에 보존했다.
- 기존 버전 코드 23→24 변경을 함께 보존한다. 이번 정리에서 추가 버전 증가는 하지 않는다.
- 현재 ADB 목록에는 연결 기기가 없다. 과거 폴드6 결과를 새 실험 결과로 간주하지 않는다.

## 다음 실험의 계약

Gemma는 사용자가 명시적으로 실행한 재료 생성에 사용한다. 결과를 검증·영구 저장한 뒤, 입력 중에는 저장된 재료를 조회한다. 실제 생성, 추론 종료 후 재사용, 재시작 후 복구, 문장 선택 결과와 입력 지연을 각각 검증한다. 모델·문장팩 다운로드는 선택 사항이고 개인 금고와 공개 문장팩의 출처를 섞지 않는다.
