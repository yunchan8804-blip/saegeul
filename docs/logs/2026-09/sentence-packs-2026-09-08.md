# 선택 문장팩 구현 계약과 검증

## 목표와 경계

개인 기록과 LLM 캐시가 비어 있어도 문맥에 맞는 로컬 이어쓰기 후보를 제공한다. 소형 기본팩은 APK에 포함하고 추가팩은 사용자가 다운로드를 선택했을 때만 받는다. 이번 작업은 기능 추가이며 기존 개인화·금고 성능 리팩터링의 완료 범위를 확대해서 해석하지 않는다.

기본팩과 추가팩은 개인 금고·사용 빈도·학습 문장 수에 합산하지 않는다. 추천 조회는 불변 메모리 인덱스만 읽는다. 준비·다운로드·검증·색인·삭제는 UI 및 키 입력 스레드를 기다리게 하지 않는다. 비밀번호·민감 입력창과 앱별 기능 차단, 전체 오프라인 모드의 기존 계약을 유지한다.

## 확정 설계

- 기본팩: `assets/sentence-packs/ko-basic-v1.txt`, 프로젝트 자체 작성 한국어 예문. 외부 말뭉치 복제와 관측 사용 빈도 주장을 하지 않는다.
- 추가팩: songys/Chatbot_data의 고정 CSV를 GitHub raw에서 받아 `label=0`의 발화를 기기에서 선별한다. 원본 문답 전체 다운로드와 일상 부분 선별을 동의 화면에 설명한다. 한국어·길이·금지 문자·부적절 표현 검사와 중복 제거를 적용한다. 자동 필터를 전체 언어 품질 검수 완료로 보지 않는다.
- 원본 URL: `https://raw.githubusercontent.com/songys/Chatbot_data/4cf20d13fc46f5037fd1c531cd566e2dd9f72974/ChatbotData.csv`
- 고정 크기: 889,842 bytes. SHA-256: `287eb129695b577321c80ad397bb3c2279164d4ca577874d129fd3db5b30afe2`. 오케스트레이터가 실제 내려받은 바이트로 확인했다.
- 실제 고정 파일 11,823행, 일상 label 0은 5,290행으로 조사됐다. README의 11,876 문답 수를 설치 문장 수로 표시하지 않는다. 적용한 문장 수는 파싱·필터링 결과로 표시한다.
- MIT 원문은 출처와 함께 앱에서 확인할 수 있게 한다. AI Hub·국립국어원 자료는 이번 배포에 포함하지 않는다.
- 저장: `noBackupFilesDir/sentence-packs`. 고정 HTTPS 호스트·버전, 리다이렉트 금지, 예상 크기 상한, SHA-256, 임시 파일과 원자 교체를 사용한다. 실패·취소는 이전 유효팩을 보존한다. 삭제와 완료가 경합해 삭제한 팩이 되살아나지 않게 직렬화한다.
- 수명: repository가 불변 snapshot과 revision을 소유한다. prepare는 비동기 멱등이며 네트워크를 사용하지 않는다. 설치·삭제·로드 후 revision 변경으로 IME 추천 캐시를 무효화한다. 진행률만 변할 때는 재계산하지 않는다.
- 조회: 마지막 문장 전체 prefix를 우선한다. 그렇지 않으면 문맥 말미 두 어절 이상이 실제 예문의 어절 경계와 일치하는 가장 긴 구간을 사용한다. 두 조회가 모두 비었을 때 마지막 한글 어절(두 음절 이상, 기능어·부탁 제외)의 정확한 경계를 조회한다. 마지막 어절이 예문의 완성 어절과 정확히 같다면 사용자 입력의 끝 공백 유무와 관계없이 NEXT_WORD로 이어준다. 단일 어절만으로 조사·어미를 확장하는 ATTACH는 금지한다. 이 약한 근거에서는 후속 전체가 네 어절 이하인 후보만 채택하고 긴 문구를 자르지 않는다. 기본/추가팩을 함께 조회하고 일치 어절 수 및 근거 종류 순으로 병합한다. 무관한 의도별 고정 문장으로 빈칸을 채우지 않는다.
- 후보: `source=sentence_pack`, `badge=기본문장`, 기존 문장 재정렬을 적용한다. `ContextualAppend`에 원래 입력 문맥을 보관해 문맥이 바뀐 후보의 삽입을 차단한다. 개인 후보 gate는 완화하지 않는다.

## 국소 UI 설계

무엇을: 기존 개인정보·AI 설정에 문장팩 관리 한 항목과 표준 다이얼로그를 추가한다.
누구에게: 새글 사용자가 기본팩을 즉시 이용하고, 추가 다운로드 여부·삭제를 직접 결정하게 한다.
제약: Android 기존 Preference/Material 스타일, 한국어 제품 문구, 최소 48dp 터치 영역, 큰 글꼴에서 스크롤 가능한 본문, 전체 화면 로딩 카드 금지.

루트 `design.md`는 admin 운영 콘솔 전용이므로 Android에 그 토큰을 적용하지 않는다. 기존 PrivacyAiSettingsFragment의 네트워크 설정과 표준 다이얼로그를 국소 참조로 사용한다. 새 탭·내비게이션·시각 토큰을 만들지 않는다. designpaca의 웹 DOM 검사 대신 실제 Android UI 계층과 화면 캡처로 크기·잘림·동작을 검증한다.

첫 Main 진입 안내는 setup 완료 및 첫 프레임 이후 한 번만 제공한다. 나중에·닫기를 기억한다. 안내 자체는 다운로드를 시작하지 않는다. 다운로드 중 진행률·취소, 실패 시 이유·재시도, 설치 후 실제 문장 수·삭제·출처를 제공한다. 다이얼로그를 닫아도 진행 상태는 저장소가 유지하고 다시 열어 볼 수 있다. 오프라인 모드를 자동으로 해제하지 않는다.

### 이전 검증 및 실패 이력

추천 개선 1차 단위 31건, 품질 재작업 후 32건이 failure/error/skip 0으로 통과했다. 실제 설치팩 조회 33회 중 후보 있는 관측은 16회였으며 중복 입력 1회가 포함된다. 무작위 평가·전반적 자연스러움 점수로 해석하지 않는다. `coverage-device-r2.log`에 query와 전체 suffix가 남아 있다. 저장소·설정 4건은 통과했지만 IME2건은 클릭 후 삽입 실패로 반려했다. 앞선 exact accessibility 실패는 `기본문장` badge 미등록으로 문구와 라벨이 결합되는 렌더링을 고쳐 해결됐다. 다음으로 CandidateViewHolder가 같은 값의 새 후보에 rebind될 때 이전 객체를 보존해 IdentityHashMap의 클릭 key를 잃는 경로를 수정했다. 새 기기 삽입 검증 전에는 개선 APK를 전송하지 않는다.

15:06 설정 진입 수정본 `saegeul-debug-sentence-packs-settings-fix-20260908.apk`를 폴드6 Taildrop으로 전송했다. SHA-256은 `B19259EC441BC4A8D8A23B10133A247657AE9B02AB6571B5733C0A0C292323D1`이다.
