# 07. 개인정보 및 보안 아키텍처 (Privacy & Security)

키보드는 사용자가 입력하는 비밀번호, 개인 메시지, 금융 정보가 통과하는 가장 민감한 시스템 소프트웨어입니다. 새글(Saegeul)은 **"안 보내는 것이 기본"**이라는 원칙 아래 설계되었습니다.

---

## 1. 데이터 처리 경계 원칙

```
┌─────────────────────────────────────────────────────────────┐
│                    기기 내 로컬 100% 완결                     │
│  - 일반 키 입력 & 한글 조합                                  │
│  - 클립보드 기록 (기본값 OFF, 로컬 암호화 DB)                    │
│  - 온디바이스 OCR & 단어장                                    │
│  - 사용량 통계 (글자수·성공여부만 기록, 프롬프트 비저장)             │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                 사용자가 직접 실행한 1회성 전송                │
│  - 글쓰기 AI (본문/수신자 확인 후 작업 버튼 누를 때만 전송)         │
│  - 고정밀 음성 (마이크 누르고 있는 동안만 오디오 스트림)           │
│  - 네트워크 GIF (검색창에 입력한 키워드만 전송)                 │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 하드웨어 레벨 보안 (Android Keystore)

- 사용자가 등록한 AI API 키, OAuth 토큰, PC 연동 암호화 키는 **Android Keystore 하드웨어 보안 칩셋**으로 암호화됩니다.
- 앱 데이터 추출, ADB 백업, Android 클라우드 기기 백업 대상에서 영구 제외됩니다.
- 사용자가 공급자 삭제 버튼을 누르면 암호화 키가 즉시 완전 소멸합니다.

---

## 3. 민감 입력창 자동 Fail-Closed

- 비밀번호 필드 (`TYPE_TEXT_VARIATION_PASSWORD`)
- 민감 정보 필드 (`TYPE_TEXT_FLAG_NO_SUGGESTIONS`)
- 개인화 학습 금지 플래그 (`IME_FLAG_NO_PERSONALIZED_LEARNING`)

위 플래그가 지정된 입력창에서는 **오타 검사, 자동완성 후보, 클립보드 기록, AI 툴바, 네트워크 연결이 하드웨어 레벨에서 일괄 차단**됩니다.

---

## 4. 검증된 0바이트 완전 오프라인 모드

앱 설정에서 **전체 오프라인 모드**를 켜면 모든 네트워크 소켓 통신이 원천 차단됩니다. Android 시스템 데이터 사용량 모니터링 기준으로 **0바이트 송수신**이 유지됨을 검증했습니다.
