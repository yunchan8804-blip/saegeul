# 03. 한국어 특화 스마트 기능 (Korean Smart Input)

새글(Saegeul)은 단순한 자판 배치를 넘어, 한국어 타이핑 시 발생하는 고유한 불편함을 해소하는 5대 지능형 입력 도구를 내장하고 있습니다.

---

## 1. 한/영 오타 즉시 자동 복구 (`KO-01`)

영문 자판 상태에서 한글을 치거나, 한글 자판에서 영문을 쳤을 때 지우고 다시 칠 필요가 없습니다.

- **작동 원리:** 두벌식/쿼티 키 매핑을 기반으로 버퍼 내용을 실시간 역변환합니다.
- **예시:** `dkssudgktpdy` 입력 후 후보창의 복구 버튼을 누르면 `안녕하세요`로 즉시 치환됩니다.
- **역방향 지원:** 한글 상태에서 영문 타이핑 오타(`앧` ➔ `doc`) 역시 동일하게 복구됩니다.

---

## 2. 초성 통합 검색 (`KO-02`)

단어 전체를 다 치지 않고 자음 초성만으로 빠르게 단어나 문장을 완성합니다.

- **작동 원리:** 내장 사전 및 사용자 단어장의 초성 인덱스를 트리 탐색합니다.
- **예시:**
  - `ㄱㅅㅎㄴㄷ` 입력 ➔ `감사합니다`
  - `ㅈㅅㅎㄴㄷ` 입력 ➔ `죄송합니다`
  - `ㅇㄴㅎㅅㅇ` 입력 ➔ `안녕하세요`

---

## 3. 조사 받침 자동 판별 (`KO-09`)

한국어에서 앞 글자의 종성(받침) 유무에 따라 조사가 달라지는 문법 규칙을 키보드가 자동으로 계산합니다.

- **앞 글자에 받침이 있는 경우:** `은`, `이`, `을`, `과` 자동 추천
  - 예: `새글` + `을` ➔ `새글을`
- **앞 글자에 받침이 없는 경우:** `는`, `가`, `를`, `와` 자동 추천
  - 예: `키보드` + `가` ➔ `키보드가`

---

## 4. 한자 음훈 변환 (`KO-05`)

단순히 한자 모양만 나열하는 것이 아니라, 해당 한자의 **음과 훈(뜻)**을 함께 표시하여 동음이의어 중 원하는 한자를 정확히 고를 수 있습니다.

- **예시:** `가` 입력 후 한자 변환 시:
  - `可` (옳을 가)
  - `家` (집 가)
  - `佳` (아름다울 가)
  - `街` (거리 가)

---

## 5. 오프라인 표준국어대사전 (31,808 표제어)

- 국립국어원 표준국어대사전 기반 31,808개 주요 어휘 데이터베이스가 기기 안에 내장되어 있습니다.
- 단어 철자 검사 및 자동완성이 외부 통신 없이 **100% 로컬 메모리**에서 즉각 실행됩니다.
