# 05. 한글 버퍼 호환 모드 (Hangul Buffer Compatibility)

Android의 일부 앱(웹뷰, 유니티/언리얼 게임, Flutter 렌더러, Jetpack Compose, 원격 데스크톱 등)은 한글의 조합 중 상태(`Composing Text`)를 표준 `InputConnection` 사양대로 처리하지 못해 글자가 겹치거나 뒤바뀌는 문제가 발생합니다. 새글(Saegeul)은 이를 완벽히 해결하는 **한글 버퍼 호환 입력 파이프라인**을 제공합니다.

---

## 1. 문제 원인 및 해결 방식

### 문제 현상
- 웹뷰(Chromium)나 특수 텍스트 엔진에서 한글 `안녕` 타이핑 시 `ㅇㅏㄴㄴㅕㅇ`으로 풀려 입력되거나, 조합 중 커서가 튀는 현상 발생.

### 새글의 해결 메커니즘
새글은 **설정 > 고급 > 한글 버퍼 호환 모드**를 통해 3가지 확정 방식을 제공합니다.

| 모드 | 작동 원리 | 적합한 환경 |
| :--- | :--- | :--- |
| **시스템 붙여넣기 (System Paste)** | 키보드 내부에서 글자를 완성한 후 시스템 클립보드 1회성 임시 버퍼를 통해 전달 | 가장 안정적이며 웹뷰 및 브라우저에 최적 |
| **Ctrl+V 에뮬레이션** | 하드웨어 키보드의 붙여넣기 키 이벤트를 에뮬레이트하여 전송 | 원격 데스크톱(RDP, AnyDesk, Termux) |
| **직접 확정 (Direct Commit)** | 중간 조합 단계를 생략하고 완성된 한글 글자 단위로 즉시 확정(`commitText`) | 빠른 타이핑 및 게임 채팅창 |

---

## 2. 2단계 엔터(Enter) 확정 계약

버퍼 호환 모드가 켜져 있을 때 엔터 키는 다음과 같이 안전하게 2단계로 분리됩니다:

1. **1회차 엔터:** 현재 조합 중인 한글 글자 확정 (글자 조합 완료)
2. **2회차 엔터:** 실제 에디터에 줄바꿈(NewLine) 또는 메시지 전송(Send) 신호 전달

이를 통해 조합 중 실수로 메시지가 전송되거나 글자가 짤리는 사고를 원천 방지합니다.
