# 02. 17가지 한국어 자판 & 조합 엔진 (Keyboard Layouts & Engine)

새글(Saegeul)은 `libhangul` C 엔진을 기반으로 기기 내 메모리에서 한글을 직접 조합합니다. 스마트폰과 태블릿을 아우르는 17가지 자판 배열과 작동 원리를 안내합니다.

---

## 1. 지원 자판 배열 전체 목록

새글은 **설정 > 입력 방식 > 한글** 또는 키보드 내 **스페이스바 롱프레스**를 통해 언제든 원하는 자판으로 즉시 전환할 수 있습니다.

### A. 모바일 최적화 자판
- **천지인 (Cheonjiin):** 모음 `ㅣ`, `ㆍ`, `ㅡ` 3개로 모든 모음을 조합하는 표준 모바일 자판.
- **천지인 플러스 (Cheonjiin+):** 자주 쓰는 자음/모음을 분리 배치하여 타수를 획기적으로 줄인 확장 천지인.
- **나랏글 / 나랏글(중앙) (Naratgul):** 기본 자음에 `획추가`, `쌍자음` 버튼을 눌러 파생 자음을 완성하는 직관적 자판. 편집 키를 가운데로 모은 중앙 배치 변형도 있다.
- **베가 / 베가(중앙) (Vega):** 팬택 베가 계열 스마트폰의 대표 자판으로, 간결한 자음/모음 배치 제공. 나랏글처럼 중앙 배치 변형이 있다.
- **한손 모아키 / 양손 모아키 (MoAKey):** 자음 키를 누른 채 모음 방향으로 밀어서(슬라이드 제스처) 한 번의 터치로 음절을 완성하는 고속 제스처 자판. 한 손으로 쓰는 배열과 양손용 배열을 따로 제공한다.

### B. 표준 쿼티 및 두벌식 계열
- **두벌식 (2-Set):** 표준 PC 쿼티 한글 자판 배열.
- **두벌식 옛글 (2-Set Yetgeul):** 두벌식에 옛한글 자모를 더한 배열.
- **단모음 (Short Vowel):** `ㅕ`, `ㅑ`, `ㅛ`, `ㅠ` 복모음을 기본 모음 연속 타건으로 조합하여 오타를 줄인 화면 자판.

### C. 세벌식 계열 (초성·중성·종성 분리)
- **세벌식 390 (3-Set 390):** 공병우 박사의 대표 세벌식 자판으로, 프로그래밍 특수문자와 한글 타이핑의 완벽한 조화.
- **세벌식 최종 (3-Set Final):** 문장 부호와 한국어 음절 빈도에 최적화된 세벌식 최종형.
- **세벌식 순아래 (3-Set Noshift):** 쉬프트 키 사용을 최소화한 실용 세벌식 자판.
- **세벌식 옛글 (3-Set Yetgeul):** 세벌식 옛한글 입력 지원 배열.
- **세벌식 두벌 자판 (3-Set Dubeol Layout):** 세벌식 엔진에서 두벌식과 같은 키 배치를 쓰는 배열.

### D. 인체공학 자판
- **안마태 (Ahnmatae):** 양손 열 손가락의 타건 빈도를 정밀하게 균등 분배하여 손목 피로도를 최소화한 자판.

## 2. 모아키 (MoAKey) 제스처 가이드

모아키는 자음 키를 터치한 상태에서 손가락을 밀어 모음을 완성합니다. 어느 방향으로 미느냐에 기본 모음이 정해지고, 미는 도중 방향을 꺾거나 손을 가운데로 되돌린 뒤 다시 밀면 다른 모음이 됩니다.

| 손가락 동작 | 조합 모음 | 입력 예시 (`ㄱ` 기준) |
| :--- | :--- | :--- |
| 오른쪽으로 밀기 | `ㅏ` | `가` |
| 왼쪽으로 밀기 | `ㅓ` | `거` |
| 위로 밀기 | `ㅗ` | `고` |
| 아래로 밀기 | `ㅜ` | `구` |
| 대각선 위쪽으로 밀기 | `ㅣ` | `기` |
| 대각선 아래쪽으로 밀기 | `ㅡ` | `그` |
| 오른쪽으로 밀다가 방향을 틀기 | `ㅐ` | `개` |
| 왼쪽으로 밀다가 방향을 틀기 | `ㅔ` | `게` |
| 위로 밀다가 방향을 틀기 | `ㅚ` | `괴` |
| 아래로 밀다가 방향을 틀기 | `ㅟ` | `귀` |
| 오른쪽으로 밀었다가 가운데로 되돌리고 다시 오른쪽으로 밀기 | `ㅑ` | `갸` |
| 왼쪽으로 밀었다가 가운데로 되돌리고 다시 왼쪽으로 밀기 | `ㅕ` | `겨` |
| 위로 밀었다가 가운데로 되돌리고 다시 위로 밀기 | `ㅛ` | `교` |
| 아래로 밀었다가 가운데로 되돌리고 다시 아래로 밀기 | `ㅠ` | `규` |
| 위로 밀었다가 가운데를 지나 오른쪽으로 밀기 | `ㅘ` | `과` |
| 아래로 밀었다가 가운데를 지나 왼쪽으로 밀기 | `ㅝ` | `궈` |

되돌린 뒤 방향을 한 번 더 틀면 `ㅘ`는 `ㅙ`로, `ㅝ`는 `ㅞ`로 바뀝니다.

---

## 3. 온디바이스 조합 엔진의 강점

- **무지연 실시간 조합:** C 언어로 작성된 `libhangul` 엔진이 JVM 오버헤드 없이 네이티브 레벨에서 자소(초성, 중성, 종성)를 조합합니다.
- **오프라인 100% 동작:** 네트워크 연결 상태와 무관하게 언제 어디서나 동일한 타이핑 속도를 보장합니다.
