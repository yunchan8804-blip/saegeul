# 06. 음성, 온디바이스 OCR & GIF 미디어 (Voice, OCR & Media)

새글(Saegeul)은 키보드를 벗어나지 않고도 음성 전사, 사진 속 글자 추출, 리액션 GIF 검색을 한 화면에서 처리할 수 있습니다.

---

## 1. 음성 받아쓰기 (Voice Transcription)

### A. 휴대폰 기본 받아쓰기 (온디바이스)
- Android 내장 음성 인식 엔진을 활용하여 외부 서버 전송 없이 로컬에서 오디오를 텍스트로 변환합니다.

### B. 고정밀 녹음 전사 (STT Cloud / PC)
- 긴 문장이나 전문 용어를 정확하게 받아쓸 때 사용합니다.
- 사용자가 마이크 버튼을 누르고 말한 뒤 정지 버튼을 눌렀을 때만 1회성 오디오 청크를 전송합니다.
- 녹음 원본 파일은 기기 디스크에 저장되지 않고 메모리에서 처리 후 즉시 파기됩니다.

---

## 2. 온디바이스 한글 OCR (Image to Text)

카메라로 찍은 문서나 갤러리 이미지 속 글자를 즉시 타이핑 텍스트로 추출합니다.

- **100% 로컬 처리:** Tesseract / ONNX 기반 경량화 신경망 모델을 기기 안에서 직접 실행합니다.
- **개인정보 보호:** 선택한 이미지 사본이나 인식된 텍스트가 외부 서버로 절대 전송되지 않습니다.
- **결과 검토:** 추출된 텍스트를 확인하고 원하는 부분만 선택하여 에디터에 삽입할 수 있습니다.

---

## 3. GIF 및 리액션 미디어 검색

키보드 툴바의 GIF 아이콘을 눌러 다양한 미디어를 검색하고 메신저에 바로 전송합니다.

| 공급자 | 데이터 전송 위치 | 특징 |
| :--- | :--- | :--- |
| **Animated Noto Emoji** | 기기 내 로컬 (검색어 외부 전송 없음) | Google Fonts 공식 애니메이션 이모지 |
| **Wikimedia Commons** | Wikimedia 공개 API | 저작권이 자유로운 오픈 미디어 |
| **KLIPY** | KLIPY API | 한국어 밈 및 리액션 GIF 최적화 |
| **GIPHY** | GIPHY API | 방대한 글로벌 트렌딩 GIF 카탈로그 |

> [!NOTE]
> '전체 오프라인 모드'가 켜져 있으면 네트워크 GIF 공급자는 자동으로 차단되며 로컬 Noto Emoji만 안전하게 작동합니다.
