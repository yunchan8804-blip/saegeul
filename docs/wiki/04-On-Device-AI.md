# 04. 기기 안 AI, 새글 AI (On-Device AI)

새글의 AI 글쓰기는 "새글 AI"라는 이름으로 휴대폰 안에서만 동작합니다. 서버로 보내는 글쓰기 API도, PC와 연결하는 프록시도 없습니다. Google Gemma 모델을 한 번 내려받아 두면, 그 뒤로는 인터넷 없이 내 말투를 배우고 다음 문장을 추천합니다.

---

## 1. 어떻게 동작하나요

```
┌───────────────────────────────┐
│          Android 새글         │
│  - 입력을 멈추면 문맥을 확인    │
│  - Gemma로 다음 문장 생성       │
│  - 화면에서 확인 후 적용        │
└───────────────┬───────────────┘
                │ 전부 이 휴대폰 안에서
                ▼
┌───────────────────────────────┐
│   새글 AI (Google Gemma 4 E2B) │
│   LiteRT-LM 엔진으로 로컬 실행   │
└───────────────────────────────┘
```

- 최초 1회, Hugging Face에서 새글 AI 모델(Google Gemma 4 E2B, 약 2.6GB)을 내려받습니다.
- 내려받은 뒤로는 완전히 기기 안에서 동작합니다. 입력한 글은 어디로도 보내지 않습니다.
- 평소 입력을 멈추면 지금까지 쓴 문맥을 바탕으로 다음 문장을 제안합니다.
- 쓸수록 내 말투를 배워 추천이 다듬어집니다.

---

## 2. 설치하기

1. **개인정보·AI > 새글 AI**에서 설치를 시작합니다.
2. 모바일 데이터로 연결돼 있으면 와이파이로 받을지, 지금 데이터로 받을지 먼저 확인합니다. (약 2.6GB이므로 와이파이를 권장합니다.)
3. 받은 파일은 무결성을 검증한 뒤 설치를 마칩니다. 검증에 실패하면 다시 받도록 안내합니다.
4. 이미 받아 둔 모델 파일이 있다면 설정에서 파일로 바로 가져올 수도 있습니다.

> [!NOTE]
> 완전 오프라인 모드에서는 모델을 새로 받을 수 없습니다. 저장 공간이 부족하면 설치 전에 안내합니다.

---

## 3. 모델 정보

| 항목 | 내용 |
| :--- | :--- |
| **모델** | Google Gemma 4 E2B |
| **실행 엔진** | LiteRT-LM (Apache-2.0 오픈소스 라이선스) |
| **용량** | 약 2.6GB |
| **받는 곳** | Hugging Face |

---

## 4. 지우면 어떻게 되나요

**개인정보·AI > 새글 AI > 모델 삭제**로 언제든 지울 수 있습니다. 지우면 AI 추천과 이어쓰기가 멈추지만, 그동안 배운 말투 데이터는 남습니다. 다시 설치하면 이어서 씁니다.

---

## 5. 음성·GIF는 별도 기능입니다

음성 받아쓰기와 GIF 검색은 새글 AI(Gemma)와 무관하게 계속 제공되는 기능입니다. 자세한 내용은 **[06. 음성, 온디바이스 OCR & GIF](06-Voice-OCR-and-Media.md)** 문서를 참고하세요. 기본은 휴대폰 자체 받아쓰기이며, 더 정확한 전사가 필요할 때만 사용자가 직접 OpenAI 음성 인식을 선택 기능으로 연결할 수 있습니다.
