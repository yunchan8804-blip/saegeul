# 0005. 레벨업 포인트는 중복 지급보다 유실을 택한다

- 상태: 채택
- 날짜: 2026-10-09

## 맥락

레벨업 보상은 "마지막 보상 레벨 기록"과 "포인트 원장 적립" 두 저장을 한 번에 원자적으로 할 수 없다. 둘 사이에서 프로세스가 죽으면 중복 지급이나 유실 중 하나가 생긴다.

## 결정

중복 지급이 유실보다 나쁘다. 새 레벨을 먼저 기록하고, 그다음 포인트를 적립한다. 레벨을 저장하지 못하면 지급하지 않고, 원장이 적립을 거부하면 레벨 기록을 이전 값으로 되돌려 다음 호출이 다시 지급하게 한다. 두 단계 사이에서 프로세스가 죽으면 그 지급은 유실된다.

## 결과

- 구현: `app/src/main/java/org/fcitx/fcitx5/android/data/points/LevelRewardStore.kt`(`grantIfLevelUp`), 커밋 `e9b26719`.
- 백업 가져오기로 복원한 높은 레벨은 `LevelRewardStore`에 지급 없이 기록해 포인트 파밍 경로를 막는다.
