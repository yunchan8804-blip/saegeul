# 0003. 읽을 수 없는 금고 파일은 덮어쓰지 않는다

- 상태: 채택
- 날짜: 2026-10-09

## 맥락

금고 파일을 읽지 못했을 때(복호화·형식·파싱 실패) 빈 상태로 보고 새로 저장하면, 나중에 읽을 수 있게 될 수도 있는 개인 학습 데이터를 덮어써 잃는다.

## 결정

- 읽기에 실패한 금고 파일은 덮어쓰거나 지우지 않는다. 해당 경로는 프로세스 안에서 읽기 차단 상태가 되고 쓰기·삭제·이전 쓰기는 거부된다.
- 연속 실패가 3회에 이르면 파일과 백업을 `<이름>.unreadable-<epochMs>`로 보존하고, 그 뒤 "파일 없음"으로 보고해 새로 학습을 시작한다.
- 사용자가 직접 지우면 읽기 차단과 관계없이 본 파일, 백업, 임시·실패 횟수 파일, 보존된 `.unreadable-*`까지 모두 삭제한다.
