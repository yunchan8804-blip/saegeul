# 0006. 버퍼 모드의 엔진 삭제 요청은 버퍼 안에서만 처리

- 상태: 채택
- 날짜: 2026-10-09

## 맥락

한글 버퍼 호환 모드는 글자를 편집기에 바로 넣지 않고 버퍼에 모은다. 이 모드에서는 입력한 글자가 편집기가 아니라 버퍼에 있으므로, fcitx 엔진이 보내는 삭제 요청(DeleteSurrounding)의 대상도 버퍼여야 한다.

## 결정

버퍼 모드에서 엔진의 삭제 요청은 편집기가 아니라 버퍼 끝에서 코드포인트 단위로 처리한다. 버퍼보다 긴 넘침분과 커서 뒤 삭제는 버린다. 엔진 reset 대기 중 도착한 삭제 요청은 무시한다.
