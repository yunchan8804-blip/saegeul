# 0004. 정밀 받아쓰기 녹음 중 키보드 숨김은 취소

- 상태: 채택
- 날짜: 2026-10-09

## 맥락

정밀 음성 전사는 중지한 뒤 녹음을 외부 공급자에 보낸다. 녹음 중에 키보드가 숨겨졌을 때 녹음을 보낼지 버릴지 정해야 했다.

## 결정

정밀 받아쓰기 녹음 중에 키보드가 숨으면 취소로 처리하고 아무것도 전송하지 않는다. 실시간 전사는 연결을 바로 닫고 받은 부분 결과도 버린다.

## 결과

- `docs/independent-fork/privacy-data-safety.md`의 정밀·실시간 음성 전사 행에 "녹음 중 키보드를 숨기면 취소" 문장을 반영했다.
- 구현 커밋 `f4fc7e5f`(음성 받아쓰기 오류 처리와 숨김 시 취소).
