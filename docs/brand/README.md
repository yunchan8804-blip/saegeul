# 새글 (Saegeul) 브랜드 및 시각 자산 가이드

새글의 공식 브랜드 아이덴티티, 로고 벡터 자산, 컬러 팔레트 및 사용 규정을 안내합니다.

## 🎨 브랜드 상징 및 조형 원리

- **네이비 바탕 (`Ink Navy`):** 독립 오픈소스 소프트웨어의 신뢰성과 견고한 보안 기반을 상징합니다.
- **아이보리 조형 (`Warm Ivory`):** 한글 자모의 유려한 획과 글쓰기의 따뜻한 인간적 감성을 표현합니다.
- **제이드 세로획 (`Fresh Jade`):** 다음 글자를 기다리는 정밀한 텍스트 커서와 지능형 타이핑을 나타냅니다.

---

## 📐 공식 컬러 팔레트 (Color Palette)

| 색상 명칭 | HEX 코드 | RGB / 용도 | 시각적 의미 |
| :--- | :--- | :--- | :--- |
| **Ink Navy** | `#101827` | `rgb(16, 24, 39)` / 기본 배경 및 어두운 표면 | 흔들림 없는 독립 제품의 안정감 |
| **Warm Ivory** | `#FFF9ED` | `rgb(255, 249, 237)` / 자모 획 및 밝은 텍스트 | 한글 조형의 유려함과 종이의 질감 |
| **Fresh Jade** | `#55D6A6` | `rgb(85, 214, 166)` / 텍스트 커서 및 액센트 | 지능형 어시스턴트와 활기찬 타이핑 |
| **Jade Bright** | `#79F1C2` | `rgb(121, 241, 194)` / 인터랙티브 하이라이트 | 버튼 호버 및 발광 글래스 효과 |
