# 새글 브랜드 자산

`saegeul-icon-master.png`은 1024px 배포 원본이고, `saegeul-icon.svg`는 Android
리소스와 크기별 PNG를 재현하는 기하학 기준이다. 네이비 바탕은 독립 제품의 안정성,
아이보리 조형은 한글 자모와 쓰기, 제이드 세로획은 텍스트 커서를 뜻한다.

- Ink Navy: `#101827`
- Warm Ivory: `#FFF9ED`
- Fresh Jade: `#55D6A6`

아이콘에는 Fcitx 로고, 펭귄, Android 로봇 또는 기존 공식 앱 자산을 사용하지 않는다.
SVG는 `CC-BY-4.0`, 앱에 포함된 파생 리소스는 프로젝트의 `LGPL-2.1-or-later`로
배포한다.
