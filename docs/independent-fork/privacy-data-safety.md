# 개인정보·Data Safety SSOT

상태: `IMPLEMENTED WITH RELEASE GATES`
기준일: 2026-07-30
범위: 독립 한국어 IME의 로컬 데이터, 네트워크 전송, 앱 내 고지, Google Play Data Safety

이 문서는 코드에서 확인한 실제 동작의 단일 기준이다. 공개 개인정보처리방침과 Play Console 답변은 이 문서보다 약하게 작성하면 안 된다.

## 1. 정책 기준

- Google Play에 게시하는 모든 앱은 Data Safety 양식을 제출하고, 데이터를 수집하지 않는 앱도 개인정보처리방침을 제공해야 한다.
- 앱과 포함된 SDK의 실제 동작을 정확히 신고할 책임은 개발자에게 있다.
- 기기 밖으로 전송되는 데이터는 짧게 처리되거나 사용자가 직접 시작한 전송이어도 Data Safety 검토 대상이다.
- 온라인 공급자가 연결 IP에서 위치를 추론할 수 있으면 `대략적 위치`, 앱 안의 검색어를 보내면 `앱 내 검색 기록` 유형을 검토한다.
- 예상하기 어려운 개인정보·민감정보 접근 또는 수집은 권한창이나 전송보다 앞선 앱 내부의 명확한 고지와 적극적 동의가 필요하다.
- 개인정보처리방침은 Play Console과 앱 안에서 모두 접근 가능해야 하며, 실제 동작과 Data Safety 답변이 서로 일치해야 한다.

공식 기준:

- https://support.google.com/googleplay/android-developer/answer/10787469
- https://support.google.com/googleplay/android-developer/answer/10144311
- https://support.google.com/googleplay/android-developer/answer/11150561

## 3. 구현된 앱 내 고지와 보호

- `DONE` AI 원문 미리보기 아래에 수신 공급자, 목적, `store=false`, 앱 사용량 비보관, 공급자 보관정책을 항상 표시한다. 작업 버튼이 해당 1회 전송의 적극적 동작이다.
- `DONE` 첫 마이크 사용 전에 온라인 음성 수신자·목적·정밀/실시간 전송 시점·앱 비보관·공급자 보관정책을 별도 화면에 표시한다. 동의 후에만 Android 마이크 권한창을 연다.
- `DONE` 첫 회의 음성 파일 선택 전에 파일 크기·길이, 수신자, 목적, 비보관, 화자 동의 책임을 별도 고지한다. 동의 후에만 시스템 파일 선택기를 연다.
- `DONE` GIF 검색 화면에 공급자별 전송 내용을 표시한다. GIPHY는 임의 식별자와 이벤트 전송까지 명시한다.
- `DONE` GIPHY 설정 삭제 시 API 설정과 임의 분석 식별자를 함께 삭제한다.
- `DONE` 클립보드 기록은 새 설치에서 기본으로 끄고, 클립보드 DB와 sidecar를 Android 클라우드 백업·기기 이전·새 ZIP 내보내기·ZIP 가져오기에서 제외한다.
- `DONE` 구 패키지 ZIP을 새 applicationId로 가져오는 version 2 lineage를 두되, 클립보드 기록과 기존 활성화 값은 이전하지 않는다.
- `DONE` 앱의 About 화면에서 오프라인으로 열리는 `개인정보·데이터 안내`를 제공한다.
- `DONE` AI·음성·GIF 키와 OAuth 토큰은 Keystore 암호화 백업 제외 저장소에 두며 일반 사용자 데이터 ZIP에 넣지 않는다.

## 4. Play Data Safety 제출 계약

기계 판독 원본은 [`play-data-safety-declaration.json`](play-data-safety-declaration.json)이며 상태는
`READY_FOR_PLAY_CONSOLE_DRAFT`다. 공개 URL·공급자 승인·Play Console 실제 입력은 아직 외부
게이트지만, Console에 넣을 기술 답변은 아래처럼 잠근다.

전역 답변:

| Data Safety 질문 | 잠근 답변 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하는가 | `예` | 선택형 온라인 기능이 데이터를 기기 밖으로 보냄 |
| 모든 수집 데이터가 전송 중 암호화되는가 | `예` | HTTPS/WSS 전용 |
| 삭제 요청 메커니즘을 제공하는가 | `아니요` | 개발자 서버·계정이 없고 공급자 전송 데이터는 해당 공급자 경로를 따름. 로컬 삭제 기능을 원격 삭제 요청으로 과장하지 않음 |
| 개발자 계정을 만드는가 | `아니요` | BYOK/OAuth는 외부 공급자 계정 |
| 데이터를 판매하는가 | `아니요` | 광고·데이터 판매 없음 |

데이터 유형별 답변:

| Play 데이터 유형 | 수집 | 공유 | 일시적 처리 | 필수 여부 | 목적 |
|---|---|---|---|---|---|
| 대략적 위치 | 예 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 내 검색 기록 | 예 | 예 | 아니요 | 선택 | 앱 기능 |
| 기타 사용자 생성 콘텐츠 | 예 | 예 | 아니요 | 선택 | 앱 기능 |
| 음성 또는 소리 녹음 | 예 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 상호작용 | 예 | 예 | 아니요 | 선택 | 앱 기능, 분석 |
| 기기 또는 기타 ID | 예 | 예 | 아니요 | 선택 | 앱 기능, 분석 |

- 대략적 위치는 온라인 공급자가 받는 연결 IP에서 추론될 수 있으므로 보수적으로 신고한다.
- GIF 검색어는 기타 사용자 생성 콘텐츠가 아니라 `앱 내 검색 기록`으로 신고한다.
- 회의 음성 파일은 `음성 또는 소리 녹음`으로 신고하며 일반 `파일·문서`로 중복 신고하지 않는다.
- `store=false`와 앱의 로컬 비보관은 공급자의 보관·남용 방지 로그까지 증명하지 않으므로 모든 유형의 `일시적 처리`는 `아니요`다.
- 공급자 역할 예외를 주장할 계약 근거가 없으므로 모든 유형을 `공유: 예`로 잠근다. 근거가 생기기 전에는 축소 신고하지 않는다.
- 사진, 일반 파일·문서, 일반 입력, 클립보드, 개인 단어장, crash log와 진단 정보는 기기 밖으로 수집하지 않는다.

릴리스 공급자 집합은 OpenAI/호환 AI, OpenAI/호환 음성, Google Fonts, KLIPY,
Wikimedia Commons, GIPHY, GitHub raw content, OAuth 공급자 8개다. GIPHY와 KLIPY는
외부 프로덕션 승인이 없는 상태에서 네트워크 요청을 활성화하지 않는다.
