# 개인정보·Data Safety SSOT

상태: `IMPLEMENTED WITH RELEASE GATES`
기준일: 2026-07-30
범위: 독립 한국어 IME의 로컬 데이터, 네트워크 전송, 앱 내 고지, Google Play Data Safety

이 문서는 코드에서 확인한 실제 동작의 단일 기준이다. 공개 개인정보처리방침과 Play Console 답변은 이 문서보다 약하게 작성하면 안 된다.

## 1. 정책 기준

- Google Play에 게시하는 모든 앱은 Data Safety 양식을 제출하고, 데이터를 수집하지 않는 앱도 개인정보처리방침을 제공해야 한다.
- 앱과 포함된 SDK의 실제 동작을 정확히 신고할 책임은 개발자에게 있다.
- 기기 밖으로 전송되는 데이터는 짧게 처리되거나 사용자가 직접 시작한 전송이어도 Data Safety 검토 대상이다.
- 예상하기 어려운 개인정보·민감정보 접근 또는 수집은 권한창이나 전송보다 앞선 앱 내부의 명확한 고지와 적극적 동의가 필요하다.
- 개인정보처리방침은 Play Console과 앱 안에서 모두 접근 가능해야 하며, 실제 동작과 Data Safety 답변이 서로 일치해야 한다.

공식 기준:

- https://support.google.com/googleplay/android-developer/answer/10787469
- https://support.google.com/googleplay/android-developer/answer/10144311
- https://support.google.com/googleplay/android-developer/answer/11150561

## 3. 구현된 앱 내 고지와 보호

- `DONE` AI 원문 미리보기 아래에 수신 공급자, 목적, `store=false`, 앱 사용량 비보관, 공급자 보관정책을 항상 표시한다. 작업 버튼이 해당 1회 전송의 적극적 동작이다.
- `DONE` 첫 마이크 사용 전에 온라인 음성 수신자·목적·정밀/실시간 전송 시점·앱 비보관·공급자 보관정책을 별도 화면에 표시한다. 동의 후에만 Android 마이크 권한창을 연다.
- `DONE` 첫 회의 음성 파일 선택 전에 파일 크기·길이, 수신자, 목적, 비보관, 화자 동의 책임을 별도 고지한다. 동의 후에만 시스템 파일 선택기를 연다.
- `DONE` GIF 검색 화면에 공급자별 전송 내용을 표시한다. GIPHY는 임의 식별자와 이벤트 전송까지 명시한다.
- `DONE` GIPHY 설정 삭제 시 API 설정과 임의 분석 식별자를 함께 삭제한다.
- `DONE` 클립보드 기록은 새 설치에서 기본으로 끄고, 클립보드 DB와 sidecar를 Android 클라우드 백업·기기 이전·새 ZIP 내보내기·ZIP 가져오기에서 제외한다.
- `DONE` 구 패키지 ZIP을 새 applicationId로 가져오는 version 2 lineage를 두되, 클립보드 기록과 기존 활성화 값은 이전하지 않는다.
- `DONE` 앱의 About 화면에서 오프라인으로 열리는 `개인정보·데이터 안내`를 제공한다.
- `DONE` AI·음성·GIF 키와 OAuth 토큰은 Keystore 암호화 백업 제외 저장소에 두며 일반 사용자 데이터 ZIP에 넣지 않는다.

## 4. Play Data Safety 제출 초안

최종 답변은 실제 릴리스에서 활성화할 공급자와 계약을 확정한 뒤 잠가야 한다.

| Data Safety 질문 | 현재 답변 초안 | 상태 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하는가 | `예` — 선택 기능에서 사용자 생성 콘텐츠, 음성, 조건부 기기/기타 ID와 앱 상호작용을 기기 밖으로 보냄 | `GATE` 공급자 범위 확정 |
| 전송 중 암호화되는가 | `예` — HTTPS/WSS 전용 | `DONE` |
| 사용자가 데이터 삭제를 요청할 수 있는가 | 로컬 데이터는 앱에서 삭제 가능. 공급자 전송 데이터는 사용자가 선택한 공급자 계정·정책을 따름 | `GATE` 공개 정책 문구·공급자 삭제 경로 |
| 앱이 개발자 계정을 만드는가 | 현재 독립 개발자 계정 없음. 사용자 BYOK/OAuth는 외부 공급자 계정 | `DONE`, 기능 추가 시 재검토 |
| 사용자 생성 콘텐츠 | AI 원문·직접 요청과 GIF 검색어 | `DECLARE` |
| 음성 녹음 | 정밀·실시간 받아쓰기와 선택한 회의 파일 | `DECLARE` |
| 사진·동영상 | OCR 이미지는 기기 밖으로 보내지 않음 | `DO NOT DECLARE AS COLLECTED` |
| 파일·문서 | 회의 음성 파일이 해당될 수 있으므로 음성 녹음과 함께 Console 분류 확인 | `GATE` Play Console 실제 항목 확인 |
| 기기 또는 기타 ID | GIPHY 임의 customer ID; 네트워크 공급자가 받는 IP 처리도 계약 기준 검토 | `DECLARE IF GIPHY SHIPS`; 나머지 `GATE` |
| 앱 상호작용 | GIPHY 노출·클릭·전송 이벤트 | `DECLARE IF GIPHY SHIPS` |
| 진단·분석 | 개발자 운영 analytics/crash SDK 없음 | `DO NOT DECLARE` |
| 위치·연락처·금융·건강 | 앱이 해당 데이터를 구조적으로 수집하지 않음. AI 원문에 사용자가 넣은 내용은 사용자 생성 콘텐츠로 처리 | `DO NOT DECLARE SEPARATELY` |

수집 목적 초안:

- AI·음성·GIF 검색어: `앱 기능`
- GIPHY 이벤트와 임의 식별자: GIPHY 통합 필수 동작이 실제 계약상 앱 기능인지 분석인지 확인 후 `앱 기능` 및 필요 시 `분석`
- 사기 방지·광고·개인화: 현재 사용하지 않음

공유 초안:

- 공급자가 개발자를 대신하는 서비스 제공자이고 계약상 목적 제한을 받으면 Google 정의상 `공유`에서 제외될 수 있지만 `수집`은 신고한다.
- BYOK로 사용자가 직접 선택한 독립 공급자, GIPHY/Wikimedia/KLIPY 전송은 사용자 시작 전송 예외와 공급자 역할을 계약별로 확인해야 한다.
- 계약 근거가 없으면 보수적으로 `공유: 예`로 제출한다.

## 5. 공개 릴리스 차단 조건

- `GATE-PRIVACY-01` 결정된 법적 게시자명, 연락 이메일, 소유 도메인
- `GATE-PRIVACY-02` 소유 도메인의 공개 개인정보처리방침 URL. 활성 URL이어야 하고, 지역 제한·편집 권한 요구·PDF만 제공하는 형태는 허용하지 않는다.
- `GATE-PRIVACY-03` Play에 포함할 AI·음성·GIF 공급자 목록과 각 공급자의 처리·보관·삭제·서비스 제공자 지위
- `GATE-PRIVACY-04` GIPHY 프로덕션 승인과 미디어 복사 승인이 없으면 GIPHY를 릴리스에서 비활성화하거나 제거
- `GATE-PRIVACY-05` 대상 연령, 아동 대상 여부, 광고 포함 여부
- `GATE-PRIVACY-06` Play Console의 실제 Data Safety 항목을 이 표와 대조한 검토 증거
- `GATE-PRIVACY-07` 공개 개인정보처리방침 URL이 앱 About와 Play listing에서 열리고, 앱 내 고지와 내용이 일치하는 실기기 증거

이 조건이 닫히기 전에는 Play 배포를 `PASS`로 표시하지 않는다.
