<b>새글은 Android용 독립 오픈소스 한국어 키보드다.</b>

Fcitx5와 libhangul을 기반으로 한글을 조합하며, 화면 키보드, 후보창, 테마,
기호·이모지와 선택형 클립보드·음성·OCR·GIF·AI 글쓰기 도구를 제공한다.

<b>첫 독립 버전 안내</b>
<ul>
<li>한글 입력에는 별도 배포되는 새글 한글 플러그인이 필요하다.</li>
<li>사용하지 않는 중국어·기타 언어 엔진은 포함하지 않는다.</li>
<li>클립보드 기록은 기본값이 꺼짐이며 백업과 데이터 이전에서 제외된다.</li>
<li>음성·OCR·GIF·AI 기능은 사용자가 직접 켜거나 실행한 경우에만 네트워크를 사용한다.</li>
</ul>

<b>오픈소스와 귀속</b>

앱 안에서 라이선스 전문, 고지, 정확한 소스 릴리스 링크를 제공한다. 새글은
Fcitx5 기반의 비공식 독립 포크이며 Fcitx 프로젝트 또는 원 Fcitx5 for Android
프로젝트와 제휴 관계가 없고 보증·승인·후원을 받지 않는다.
