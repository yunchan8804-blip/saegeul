<b>Saegeul is an independent open-source Korean keyboard for Android.</b>

It provides Korean composition through Fcitx5 and libhangul, a configurable
on-screen keyboard, candidates, themes, symbols, emoji, and optional clipboard,
voice, OCR, GIF, and AI writing tools.

<b>First independent release</b>
<ul>
<li>The separate Saegeul Hangul Plugin is required for Korean input.</li>
<li>Unused Chinese and other language engines are not included.</li>
<li>Clipboard history is off by default and excluded from backup and migration.</li>
<li>Voice, OCR, GIF, and AI features use the network only when the user explicitly enables or invokes them.</li>
</ul>
