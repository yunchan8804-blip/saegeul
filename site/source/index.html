소스 코드와 배포 파일

개발 중인 코드는 GitHub 저장소에서 공개한다. 설치 가능한 공식 파일은 GitHub Releases에서 제공한다.

소스 코드
새글 GitHub 저장소에서 코드와 변경 기록을 볼 수 있다.
설치 파일
GitHub Releases에서 새글 앱과 한글 플러그인을 받을 수 있다.
릴리스 자료
각 릴리스에는 대응 소스와 체크섬, 소프트웨어 구성 명세가 함께 제공된다.

라이선스 안내

새글은 파일과 구성요소에 표시된 오픈소스 라이선스를 따른다.

새글에서 작성한 코드
별도 표시가 없는 경우 LGPL-2.1-or-later로 공개한다.
Fcitx5와 libhangul
원 프로젝트와 각 파일에 표시된 저작권, 라이선스 조건을 유지한다.
외부 라이브러리와 데이터
각 구성요소의 원 라이선스와 저작권 고지를 적용한다.
라이선스 전문 저작권과 오픈소스 고지

사용한 오픈소스

새글은 다음 프로젝트를 기반으로 하며 각 프로젝트의 라이선스와 저작권을 존중한다.

Fcitx5 for AndroidAndroid 기반 프로젝트 Fcitx5입력기 프레임워크 libhangul한글 입력 엔진

독립 프로젝트 안내

새글은 Fcitx5를 기반으로 한 비공식 독립 포크다. Fcitx 프로젝트 또는 원 Fcitx5 for Android 프로젝트와 제휴 관계가 없으며 보증, 승인, 후원을 받지 않는다.

원 저작권과 오픈소스 라이선스 표시는 유지한다. 새글에서 추가하거나 수정한 부분과 배포는 Yun Chan이 책임진다.

직접 빌드하기

개발자는 저장소를 내려받아 새글 앱과 한글 플러그인을 직접 빌드할 수 있다.

기본 빌드 명령 보기 
git clone --recurse-submodules https://github.com/yunchan8804-blip/saegeul.git
cd saegeul
./gradlew :app:assembleRelease :plugin:hangul:assembleRelease

자세한 준비 사항은 저장소 안내에서 확인하고, 기여와 버그 보고는 새글 Issues에서 진행한다.
