Release contract

릴리스마다 자동으로 확인한다.

공개 APK와 AAB는 아래 자료가 모두 준비되고 서로 같은 Git 태그를 가리킬 때만 배포한다.

  • 전체 소스최상위 저장소와 재귀 서브모듈의 정확한 커밋, Gradle·CMake 빌드 스크립트를 포함한 <tag>-source.tar.gz.
  • 무결성소스 아카이브와 바이너리의 SHA-256, 최상위 커밋·트리·서브모듈 경로와 해시를 담은 manifest.
  • 구성 명세CycloneDX 1.6 SBOM, Release 의존성 라이선스 목록, Unknown·누락 0 검사.
  • 법적 고지LGPL 2.1, GPL 2.0, Apache 2.0 전문, 제3자 라이선스, NOTICE와 FORK-NOTICE를 APK 안과 릴리스에 제공.
Licensing

원 저작권은 유지하고 새 작업의 책임을 밝힌다.

앱의 기본 라이선스는 LGPL-2.1-or-later다. Fcitx5, libhangul과 모든 제3자 구성요소는 각 파일과 배포 고지에 적힌 원 라이선스·저작권을 따른다.

첫 독립 제품 APK에서는 중국어 fcitx5-chinese-addons, pinyin.lua, 사용하지 않는 언어 플러그인을 제외한다. 소스 저장소에는 upstream 추적과 해당 소스의 라이선스 의무를 위해 기록을 보존한다.

독립 포크 고지

새글은 Fcitx5를 기반으로 한 비공식 독립 포크다. Fcitx 프로젝트 또는 원 Fcitx5 for Android 프로젝트와 제휴 관계가 없으며 보증·승인·후원을 받지 않는다.
