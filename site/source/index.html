사용한 오픈소스 계보

새글은 다음 오픈소스 프로젝트의 위대한 기여를 기반으로 탄생했습니다.

Fcitx5 for Android Android 입력기 프레임워크 기반 Fcitx5 차세대 다국어 입력기 코어 libhangul 한국어 자소 조합 엔진

독립 프로젝트 고지

새글은 Fcitx5를 기반으로 한 비공식 독립 포크입니다. Fcitx 프로젝트 또는 원 Fcitx5 for Android 프로젝트와 공식 제휴 관계가 없으며, 원 프로젝트의 보증·승인·후원을 받지 않습니다.

원 저작권과 오픈소스 라이선스 표시는 온전히 유지됩니다. 독립 포크에서 추가·수정한 기능과 공식 배포물에 대한 모든 책임은 Yun Chan에게 있습니다.

직접 빌드하기

개발자는 서브모듈을 포함한 저장소를 클론하여 로컬에서 서명 및 빌드할 수 있습니다.

git clone --recurse-submodules https://github.com/yunchan8804-blip/saegeul.git
cd saegeul
./gradlew :app:assembleRelease :plugin:hangul:assembleRelease

빌드 환경 요구사항 및 서명 키 설정 절차는 저장소 README 및 docs/independent-fork/ 문서를 참조하세요.
