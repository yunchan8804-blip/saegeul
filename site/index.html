AI가 하는 일

여섯 가지
부탁.

새글의 AI는 먼저 나서지 않는다. 내가 AI 버튼을 연 그 순간에만 지금 쓰던 글을 읽고, 결과는 넣기 전에 보여준다.

비밀번호 입력창과 오프라인 모드에서는 아예 열리지 않는다.

01

교정

맞춤법, 띄어쓰기, 조사를 고친다. 어디가 바뀌는지 표시해 주고 원하는 부분만 적용한다.

02

말투 바꾸기

존댓말, 카톡체, 업무 메일, 정중한 거절, 사과, 고객 응대로 같은 내용을 다시 쓴다.

03

문장 생성

빈 입력창에서도 쓴다. 서로 다른 문장 세 개를 받아 마음에 드는 하나를 고른다.

04

답장 초안

받은 메시지를 공유하거나 붙여 넣으면 답장 초안을 만든다. 보관은 5분, 그다음엔 사라진다.

05

번역

한국어와 영어, 일본어, 중국어 사이를 오간다. 결과를 확인한 뒤 정확히 한 번 바꿔 넣는다.

06

직접 지시

원하는 대로 적어서 시킨다. 지시를 쓰는 자리도 쓰던 자판, 쓰던 테마, 쓰던 높이 그대로다.

연결하는 법

세 단계면
끝난다.

휴대폰과 컴퓨터가 같은 tailnet에 있으면 서로를 찾는다. 연결은 Tailscale HTTPS로만 열고 평문 HTTP는 쓰지 않는다.

  1. 1

    컴퓨터에 Companion 설치

    Windows에서 설치 스크립트를 한 번 실행한다. 로그인된 Codex CLI 또는 Claude Code를 그대로 사용한다.

  2. 2

    휴대폰이 컴퓨터를 찾기

    같은 tailnet 안에서 발견된 컴퓨터가 목록에 뜬다. 인증서와 정보를 확인한 뒤 다음으로 넘어간다.

  3. 3

    내가 승인

    승인한 컴퓨터만 연결한다. CLI의 로그인 토큰은 컴퓨터에 남고, 휴대폰에는 연결 권한만 저장한다.

컴퓨터 없이 쓰려면 OpenAI나 호환 엔드포인트의 API 키를 직접 넣어도 된다. 키는 암호로 잠가 보관하고 백업에서 제외한다.

각 서비스의 구독료, 사용 한도, 약관은 그대로 적용된다. 컴퓨터 연결은 현재 글쓰기 AI만 제공하며 음성은 포함하지 않는다.

완전 오프라인 모드

한 번 켜면 AI, 온라인 전사, 네트워크 GIF, 모델 내려받기를 모두 막는다. 실제로 통신이 0바이트인지 시스템 통계로 확인해 두었다.

비밀번호 입력창

민감한 입력창에서는 검사도, 기록도, 전송도 하지 않는다. 켜 둔 기능이 있어도 그 창에서는 멈춘다.

클립보드 기록

새 설치에서는 꺼져 있다. 켜면 앱 안에만 남고 클라우드 백업, 기기 이전, 내보내기에서 빠진다.

열쇠 보관

API 키와 연결 토큰은 Android Keystore로 잠가 백업 제외 영역에 둔다. 로그에도 남기지 않는다.

음성 입력

기본은 휴대폰 받아쓰기다. 인터넷도 계정도 필요 없다. 정밀한 전사가 필요하면 내 키를 직접 연결했을 때만 온라인 모드가 열린다.

회의 녹음은 화자를 나눠 보여주고, 체크한 구간만 넣는다.

GIF와 이모지

반응할 GIF를 키보드 안에서 찾아 바로 보낸다. 공급자를 직접 고르고, 검색어가 어디로 가는지 화면에서 확인한 뒤 쓴다.

공급자별 결과는 섞지 않고 출처와 저작자를 함께 표시한다.

사진 속 글자

이미지에서 글자를 읽어 입력창에 넣는다. 고른 이미지와 인식 결과는 기기 밖으로 나가지 않는다.

한국어 인식 모델은 내가 받기를 눌렀을 때만 내려받는다.

화면이 바뀌면 키보드도 바뀐다. 앱마다 다른 설정을 기억하고, 입력하는 동안 높이가 흔들리지 않는다.

폴드와 태블릿

펼치면 좌우로 나뉜 분할 키보드가 된다. 접었을 때와 펼쳤을 때, 세로와 가로를 각각 기억한다.

흔들리지 않는 툴바

기능 툴바는 기본 한 줄이다. 내가 펼침 버튼을 누른 세션에서만 두 줄이 되고, 입력 중에 제멋대로 커지지 않는다.

앱별 프로필

앱마다 자판, 테마, 툴바, AI 허용 여부를 따로 정한다. 업무 앱과 채팅 앱을 다르게 쓸 수 있다.

한지와 단청

한국 색을 담은 밝은 한지 테마와 어두운 단청 테마를 넣었다. 색과 배경 이미지를 직접 바꿔도 된다.

  3. 3

    기본으로 선택

    입력창에서 새글을 고르면 끝이다. 한글과 영어 자판이 처음부터 함께 켜져 있다.
