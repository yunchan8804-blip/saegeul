설치와 시작

공식 릴리스의 두 APK를 설치하고 Android에서 새글을 켠다.

무엇을 내려받아야 하나?

GitHub Releases에서 같은 태그의 사용자 앱 APK와 한글 플러그인 APK를 받는다. 파일 이름은 각각 net.chanpaca.saegeul, net.chanpaca.saegeul.plugin.hangul로 시작한다.

한글 플러그인을 따로 설치해야 하나?

현재 릴리스에서는 그렇다. 메인 앱과 한글 플러그인을 모두 설치해야 한글 엔진이 검색된다. 두 파일은 항상 같은 릴리스 태그에서 받아야 한다.

설치한 뒤 키보드는 어디서 켜나?

Android의 설정 > 일반 관리 > 키보드 목록 및 기본값에서 새글을 켜고 기본 키보드로 선택한다. 제조사와 Android 버전에 따라 메뉴 이름은 조금 다를 수 있다.

사용자판과 개발판은 무엇이 다른가?

사용자판은 일반 사용에 필요한 화면만 보여 주고 서명된 APK와 AAB로 배포한다. 개발판은 진단과 엔진 관리 메뉴가 있으며 별도 패키지로 설치된다. 일상 사용에는 사용자판을 선택하면 된다.

AI와 내 컴퓨터 연결

새글 안에서 문장을 고치고, 바꾸고, 만들고, 답장할 수 있다.

추가 API 사용료 없이 쓸 수도 있다.

Windows 컴퓨터에 로그인된 Codex 또는 Claude Code를 연결하면 별도 API 키 과금 없이 기존 구독 범위에서 글쓰기 AI를 실행한다. 각 서비스의 구독료, 사용 한도, 약관은 그대로 적용된다.

AI로 무엇을 할 수 있나?

맞춤법과 띄어쓰기 교정, 존댓말과 업무 문체 변환, 답장 초안, 문장 3개 생성, 요약과 번역, 직접 요청을 키보드 안에서 실행할 수 있다. 결과를 먼저 보고 교체, 뒤에 넣기, 복사, 취소를 선택한다.

Codex나 Claude 구독을 그대로 쓸 수 있나?

가능하다. Windows의 새글 AI Companion이 이미 로그인된 Codex CLI 또는 Claude Code를 사용한다. Android에는 CLI의 로그인 토큰이나 API 키를 복사하지 않고, 휴대폰 전용 연결 권한만 저장한다.

컴퓨터 연결은 어떻게 시작하나?

현재는 Windows 컴퓨터에서 새글 소스의 scripts/install-ai-provider-companion-tray.ps1을 실행해 Companion을 설치하고 Tailscale 연결을 준비한다. 그다음 새글의 개인정보·AI > 내 컴퓨터 연결에서 발견된 컴퓨터를 확인하고 승인한다.

컴퓨터와 휴대폰은 같은 tailnet에 있어야 한다. 연결은 Tailscale Serve HTTPS로만 허용하고 평문 HTTP는 사용하지 않는다.

내 문장과 로그인 정보는 어디로 가나?

실행을 누른 문장과 요청만 내 컴퓨터의 Companion으로 보내고, 로그인된 CLI가 해당 AI 서비스에 전달한다. Companion은 요청, 결과, Bearer token을 로그에 남기지 않는다. Codex와 Claude의 로그인 정보는 컴퓨터에 남는다.

Codex나 Claude 연결로 음성 받아쓰기도 되나?

아니다. 현재 컴퓨터 Companion은 글쓰기 AI만 제공한다. 음성은 휴대폰 받아쓰기를 쓰거나, 고급 설정에서 사용자가 직접 OpenAI 음성 API 키를 연결한다.

음성, GIF, OCR

필요할 때만 열고, 보낼 대상과 처리 위치를 먼저 확인한다.

음성 입력은 인터넷이 꼭 필요한가?

기본 휴대폰 받아쓰기는 현재 기기의 음성 입력기로 전환한다. OpenAI 실시간 또는 정밀 받아쓰기를 직접 선택한 경우에만 별도 STT 키와 네트워크가 필요하다.

왜 마이크 권한을 요청하나?

사용자가 온라인 받아쓰기를 시작할 때 음성을 녹음하기 위해 쓴다. 첫 사용 전에 수신자와 목적을 알리고 동의를 받은 뒤 Android 권한창을 연다. 녹음 파일과 전사문은 앱의 파일, 캐시, 설정, 백업, 로그에 남기지 않는다.

GIF 검색어는 어디로 가나?

Animated Noto Emoji는 검색어를 기기에서 비교한다. KLIPY, Wikimedia Commons, GIPHY를 고르면 검색어가 해당 공급자에 전송된다. 검색 화면에서 현재 공급자와 전송 내용을 확인할 수 있다.

OCR 사진이 서버로 전송되나?

아니다. 선택한 이미지와 인식 결과는 기기 안에서 처리한다. 사용자가 한국어 OCR 모델 받기를 누른 경우에만 고정 모델 파일을 GitHub에서 내려받는다.

개인정보와 데이터

평소 입력은 로컬에서 처리하고, 선택형 기능은 사용자의 동작을 전송 조건으로 삼는다.

일반 입력 내용이 개발자 서버로 전송되나?

아니다. 일반 키 입력과 한글 조합은 기기 안에서 처리한다. 비밀번호와 민감 입력창에서는 텍스트 검사와 네트워크 입력 기능을 먼저 차단한다.

클립보드 기록은 기본으로 켜져 있나?

아니다. 새 설치에서는 꺼져 있다. 직접 켜면 앱 전용 데이터베이스에 저장하고, Android 클라우드 백업과 기기 이전, 사용자 데이터 ZIP, 네트워크 전송에서 제외한다. 설정에서 개별 또는 전체 삭제할 수 있다.

기존 Fcitx5 for Android 데이터를 자동으로 읽나?

자동으로 읽지 않는다. 기존 앱에서 사용자가 직접 내보낸 ZIP을 새글에서 가져오는 방식만 제공한다. 클립보드 기록과 기존 활성화 값은 이전하지 않는다.

온라인 기능을 전부 끌 수 있나?

가능하다. 개인정보·AI 설정의 전체 오프라인 모드를 켜면 AI, 온라인 음성 전사, 네트워크 GIF, OCR 모델 다운로드를 차단한다. 자세한 데이터 흐름은 개인정보처리방침에서 확인할 수 있다.

소스와 지원

공식 배포와 원 프로젝트를 구분하고, 같은 태그의 소스로 확인할 수 있다.

Fcitx 공식 앱인가?

아니다. 새글은 Fcitx5를 기반으로 한 비공식 독립 포크다. Fcitx 프로젝트 또는 원 Fcitx5 for Android 프로젝트와 제휴 관계가 없으며 보증, 승인, 후원을 받지 않는다.

배포된 바이너리와 같은 소스는 어디에 있나?

GitHub Releases에서 같은 태그의 재귀 소스 아카이브, SHA-256, 서브모듈 해시, 빌드 스크립트, CycloneDX SBOM을 함께 제공한다. 자세한 계약은 소스와 라이선스에 정리돼 있다.

문제나 보안 취약점은 어디에 알리나?

일반 문제는 GitHub Issues에 남긴다. 비밀값이나 공개하면 위험한 내용은 이슈에 올리지 말고 yunchan@chanpaca.net로 보낸다.
