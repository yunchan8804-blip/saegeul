설치와 시작

공식 릴리스의 두 APK를 설치하고 Android에서 새글을 켭니다.

어떤 파일을 내려받아야 하나요?

GitHub Releases에서 같은 버전 태그의 사용자 앱 APK와 한글 플러그인 APK를 함께 내려받아야 합니다. 파일명은 각각 net.chanpaca.saegeul, net.chanpaca.saegeul.plugin.hangul로 시작합니다.

한글 플러그인을 왜 따로 설치해야 하나요?

새글은 모듈화된 libhangul C 엔진 아키텍처를 따릅니다. 메인 앱과 한글 플러그인을 모두 설치해야 한글 입력 엔진이 정상 검색됩니다. 두 파일은 항상 동일한 릴리스 태그에서 받아야 버전 불일치가 발생하지 않습니다.

설치 시 "출처를 알 수 없는 앱" 또는 "안전하지 않은 앱" 경고가 뜹니다

Google Play Store 외부에서 APK를 직접 내려받았을 때 Google Play Protect가 아직 등록되지 않은 서명으로 인식하여 표시하는 표준 안내입니다. 앱 자체의 결함이나 악성코드가 아닙니다.

경고 창에서 자세히 보기 > 무시하고 설치를 누르면 정상 설치됩니다. 설치가 차단될 경우 Play 스토어 > 프로필 > Play Protect > 설정에서 기기 보안 검사를 일시 해제 후 설치를 완료하세요.

내려받은 파일의 무결성은 아래 공식 서명 지문으로 언제든 직접 검증할 수 있습니다.

공식 서명 인증서 지문(SHA-256)을 확인하는 방법

새글 사용자판과 한글 플러그인은 동일한 단일 릴리스 키로 서명됩니다.

3B:08:8B:5C:6A:69:E3:6C:62:80:2E:F5:D4:33:BD:9D:84:5B:8E:98:09:27:8E:13:13:36:A5:03:DA:90:1A:66

Android SDK 터미널에서 apksigner verify --verbose --print-certs 파일명.apk 명령으로 위 지문과 v1/v2/v3 서명을 직접 검증할 수 있습니다.

특정 게임이나 웹뷰 앱에서 한글 조합이 깨질 때의 대처법

일부 앱은 한글 조합 중인 중간 버퍼(Composing Text)를 정상 처리하지 못합니다. 설정 > 고급 > 한글 버퍼 호환 모드를 켜면 키보드 내부에서 글자를 완성한 후 한 덩어리로 전달합니다. 시스템 붙여넣기, Ctrl+V, 직접 확정 방식 중 선택할 수 있습니다.

AI와 내 컴퓨터 연결

추가 API 사용료 없이 기존 Codex/Claude 구독을 모바일에서 활용합니다.

추가 API 요금 0원 원리

내 Windows PC에 이미 로그인된 Codex CLI 또는 Claude Code를 새글 Companion이 로컬에서 프록시합니다. 별도 유료 API 키 결제 없이 기존 구독 사용량 내에서 동작합니다.

내 컴퓨터와 연결하려면 어떻게 해야 하나요?

1. Windows PC에서 새글 소스의 설치 스크립트 scripts/install-ai-provider-companion-tray.ps1을 실행해 Companion을 켭니다.

2. 휴대폰과 PC가 같은 Tailscale tailnet에 연결되어 있는지 확인합니다.

3. 새글 앱의 개인정보·AI > 내 컴퓨터 연결에서 발견된 PC를 승인합니다. 연결은 Tailscale Serve HTTPS 종단간 암호화로만 통신합니다.

내 문장과 로그인 토큰이 유출되지 않나요?

Codex나 Claude의 로그인 토큰과 세션은 PC에만 머무르며 모바일 앱으로 복사되지 않습니다. 모바일에는 PC와 통신하기 위한 1회용 인증 키만 보관됩니다. Companion은 프롬프트 원문, 결과, 토큰을 디스크 로그에 남기지 않습니다.

PC 없이 모바일 단독으로 AI를 쓸 수도 있나요?

네. 개인정보·AI > AI 공급자에서 OpenAI, Anthropic 또는 OpenAI 호환 API 엔드포인트의 키를 직접 등록하여 사용할 수 있습니다. 등록된 키는 Android Keystore 하드웨어 암호화 저장소에 보관됩니다.

음성, GIF, OCR

필요할 때만 켜고, 데이터 전송 위치를 사용자가 완전히 제어합니다.

음성 입력 시 데이터가 외부로 나가나요?

기본 휴대폰 받아쓰기는 기기 내장 음성 인식기로 동작하며 외부 전송이 없습니다. 사용자가 정밀 받아쓰기 모드에서 OpenAI STT API 키를 직접 지정한 경우에만 해당 오디오 청크가 전송됩니다.

사진 속 글자 읽기(OCR)는 사진을 서버로 보내나요?

아닙니다. OCR은 기기 안에서 Tesseract/ONNX 로컬 모델을 통해 100% 온디바이스로 처리됩니다. 선택한 사진이나 인식된 텍스트는 네트워크로 전송되지 않습니다.

GIF 검색 시 어떤 정보가 전달되나요?

Animated Noto Emoji는 기기 내에서 키워드를 매칭합니다. KLIPY, GIPHY, Wikimedia를 선택했을 때만 사용자가 입력한 검색어가 해당 미디어 공급자에게 전송됩니다.

개인정보와 데이터

평소 입력은 100% 로컬에서 처리하며 추적 코드가 없습니다.

내가 타이핑하는 키 입력이 개발자 서버로 전송되나요?

절대 전송되지 않습니다. 새글은 개발자 운영 서버, 광고 SDK, 분석 트래커, 사용자 계정 시스템이 전혀 없는 순수 독립 오픈소스 소프트웨어입니다.

네트워크 기능을 완전히 차단하는 방법이 있나요?

개인정보·AI 설정에서 전체 오프라인 모드를 켜면 AI, 음성 전사, 네트워크 GIF, OCR 모델 다운로드가 하드웨어 레벨에서 일괄 차단되며, 통신량이 0바이트로 유지됩니다.
