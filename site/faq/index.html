FAQ
한글 플러그인을 따로 설치해야 하나?
첫 독립 버전에서는 그렇다. 메인 앱과 kr.twentyoz.saegeul.plugin.hangul 플러그인을 함께 설치해야 한글 엔진이 검색된다. 이후 플러그인을 메인 APK에 번들링하는 변경은 설치·검색·데이터 이전 회귀 검증을 마친 뒤 진행한다.
일반 입력 내용이 서버로 전송되나?
아니다. 일반 키 입력과 한글 조합은 기기에서 처리한다. 글쓰기 AI, 온라인 음성, 네트워크 GIF 같은 선택 기능은 전송 내용을 먼저 알리고 사용자가 직접 실행할 때만 설정한 외부 공급자에 보낸다. 전체 오프라인 모드로 모두 차단할 수 있다.
왜 INTERNET과 RECORD_AUDIO 권한이 있나?
INTERNET은 사용자가 실행하는 AI·음성·GIF·OCR 모델 다운로드에, RECORD_AUDIO는 사용자가 시작하는 온라인 받아쓰기에 쓴다. 마이크 권한은 별도 고지와 동의 뒤에만 요청한다.
기존 Fcitx5 for Android 데이터를 자동으로 읽나?
몰래 읽지 않는다. 기존 앱에서 사용자가 명시적으로 내보낸 ZIP을 새글에서 가져오는 방식만 제공한다. 클립보드 기록과 기존 활성화 값은 이전하지 않는다.
배포된 바이너리와 같은 소스는 어디에 있나?
GitHub Releases에서 바이너리와 동일 태그의 재귀 소스 아카이브, SHA-256, 서브모듈 해시, 빌드 스크립트와 CycloneDX SBOM을 같은 다운로드 위치에 제공한다. 자세한 계약은 소스와 라이선스에서 확인할 수 있다.
Fcitx 공식 앱인가?
아니다. 새글은 Fcitx5 기반 비공식 독립 포크이며 Fcitx 프로젝트 또는 원 Fcitx5 for Android 프로젝트와 제휴 관계가 없고 보증·승인·후원을 받지 않는다.
문제나 보안 취약점은 어디에 알리나?
일반 문제는 GitHub Issues에 남긴다. 비밀값이나 공개하면 위험한 보안 내용은 이슈에 올리지 말고 yunchan@twentyoz.kr로 보낸다.
