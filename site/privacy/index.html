일반 타이핑은 기기 안에서 100% 로컬 처리되며, 외부 네트워크 연결은 사용자가 직접 승인하고 실행할 때만 일어납니다.

기기 내 100% 로컬 완결 한글 조합, 클립보드, OCR, 개인 단어장

일반 타이핑 원문과 사전 데이터는 개발자 서버로 전송되지 않으며 어떠한 외부 트래커도 포함하지 않습니다.

사용자 직접 승인 시에만 전송 AI 글쓰기, 온라인 음성, 네트워크 GIF

수신 대상과 전송 내용을 화면에서 먼저 확인하고, 사용자가 실행 버튼을 누른 작업에 한해서만 1회성으로 전송됩니다.

목차

처리자와 범위 기기 내 로컬 데이터 사용자 승인 외부 전송 Google Play Data Safety 보관 및 제어 권한 보안과 Keystore 웹사이트 방침 변경 및 문의처

처리자와 적용 범위

앱, 한글 플러그인, 이 웹사이트 전반에 걸쳐 동일한 데이터 보호 원칙을 적용합니다.

새글(Saegeul)의 개발자이자 개인정보 처리자는 Yun Chan입니다. 본 방침은 Android 애플리케이션 net.chanpaca.saegeul, 공식 한글 플러그인 net.chanpaca.saegeul.plugin.hangul, 그리고 공식 웹사이트 saegul.chanpaca.net에 적용됩니다.

일반 한글 입력은 기기 안에서만 처리됩니다.

키보드로 입력하는 일반 텍스트, 조합 중인 글자, 사전 검색어는 개발자 서버나 제3자 서버로 전송되지 않습니다.

기기 안에서만 처리하는 데이터

기능을 활성화하더라도 아래 데이터는 기기 밖으로 절대 수집되거나 전송되지 않습니다.

일반 타이핑 & 한글 조합

Fcitx5 및 libhangul C 엔진이 기기 내 메모리에서 직접 글자를 조합합니다. 비밀번호 및 민감 입력창에서는 텍스트 검사와 네트워크 기능을 원천 차단합니다.

클립보드 기록

새 설치 시 기본값은 꺼짐입니다. 켜더라도 기기 내 앱 전용 암호화 데이터베이스에만 저장되며, Android 클라우드 백업과 기기 이전 대상에서 제외됩니다.

온디바이스 OCR & 단어장

선택한 이미지와 텍스트 인식 결과, 사용자가 직접 등록한 개인 단어장은 기기 내에서만 처리되며 외부로 복사되지 않습니다.

AI 사용량 메트릭

오직 성공/실패 횟수와 글자 수 통계만 로컬에 기록됩니다. 프롬프트 원문, 생성 결과, API 키, URL은 사용량 로그에 남지 않습니다.

사용자가 직접 시작하는 외부 전송

사용자가 특정 버튼을 누른 순간에만 선택한 공급자와 종단간 암호화(HTTPS/WSS)로 통신합니다.

설정에서 '전체 오프라인 모드'를 켜면 아래 모든 네트워크 기능이 0바이트로 완전 차단됩니다.

글쓰기 AI

화면에 표시된 원문과 사용자의 작업 지시를 지정된 AI 공급자(Codex, Claude, OpenAI 등)에 전송합니다. 본문과 수신자를 확인하고 작업 버튼을 누른 경우에만 1회 전송되며 store=false(학습 비저장)를 요청합니다.

내 컴퓨터 연결(Companion) 사용 시에는 본문이 승인된 Tailscale HTTPS 터널을 거쳐 PC의 CLI로 전달되며, 로그인 토큰은 PC에만 남습니다.

온라인 음성

기본 '휴대폰 받아쓰기'는 로컬 변환이며, 사용자가 OpenAI STT 키를 직접 연결해 실시간/정밀 전사를 요청했을 때만 마이크 오디오 스트림이 해당 공급자로 전송됩니다. 녹음 원본은 파일 시스템에 저장되지 않습니다.

GIF 및 미디어

Animated Noto Emoji는 기기 내에서 키워드를 매칭합니다. KLIPY, GIPHY, Wikimedia를 선택해 검색했을 때만 검색어가 해당 미디어 공급자에게 전송됩니다.

인증 정보

사용자가 입력한 API 키와 인증 토큰은 Android Keystore 하드웨어 암호화로 보호되는 백업 제외 저장소에 저장됩니다. 공급자 삭제 시 즉시 완전 파기됩니다.

Google Play Data Safety

선택형 기능이라도 외부로 전송 가능한 데이터 항목을 투명하게 고지합니다.

대략적 위치네트워크 연결 시 공급자가 확인하는 IP 주소 기반 위치
앱 내 검색어네트워크 GIF 공급자 선택 시 전송되는 미디어 검색 키워드
사용자 생성 콘텐츠AI 글쓰기 버튼을 눌렀을 때 전달되는 프롬프트 및 원문
음성 녹음온라인 음성 전사를 직접 실행했을 때의 음성 데이터

보관, 삭제 및 사용자 제어

기기 내 모든 데이터는 사용자가 언제든 즉시 열람하고 완전히 삭제할 수 있습니다.

클립보드 기록
앱 설정에서 개별 항목 삭제 또는 전체 기록 즉시 삭제가 가능합니다.
개인 단어장
사용자가 단어를 직접 삭제하거나 앱 데이터를 초기화할 때까지 로컬에만 보관됩니다.
AI / 음성 공급자
공급자 삭제 버튼을 누르면 Android Keystore에 저장된 API 키와 토큰이 영구 파기됩니다.
권한 및 네트워크
Android 설정에서 마이크 권한을 철회하거나, 앱 내 '전체 오프라인 모드'를 활성화할 수 있습니다.

보안과 권한

모든 네트워크 전송은 HTTPS 또는 WSS 프로토콜로 강제되며, 인증 키는 Android Keystore 기반 비인가 접근 차단 저장소에 보관됩니다. 새글은 어떠한 광고 SDK나 분석 추적 라이브러리도 탑재하지 않습니다.

이 웹사이트의 방침

본 웹사이트(saegul.chanpaca.net)는 쿠키, 추적 스크립트, 광고를 일절 사용하지 않는 순수 정적 웹페이지입니다. 사이트를 호스팅하는 GitHub Pages의 기본 접속 로그(IP, User-Agent)는 GitHub의 자체 개인정보 정책을 따릅니다.
