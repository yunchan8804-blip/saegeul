새글(Saegeul)의 개발자이자 배포자, 개인정보 처리자는 Yun Chan이다. 이 방침은 Android 앱 net.chanpaca.saegeul, 한글 플러그인, saegul.chanpaca.net에 적용된다.

일반 한글 입력은 기기 안에서 처리한다.

키 입력과 조합 중인 글을 개발자가 운영하는 서버로 보내거나 입력 원문으로 기록하지 않는다.

기기 안에서 처리하는 데이터

기능을 켜더라도 아래 데이터는 기기 밖으로 수집하지 않는다.

일반 입력

Fcitx5와 libhangul이 기기 안에서 조합한다. 비밀번호, 민감, 개인화 학습 금지 입력창에서는 텍스트 검사와 네트워크 입력을 먼저 차단한다.

클립보드

새 설치에서는 기록이 꺼져 있다. 직접 켜면 앱 전용 데이터베이스에 저장하고, 백업과 기기 이전, ZIP 내보내기와 네트워크 전송에서 제외한다.

OCR와 개인 단어장

선택한 이미지와 인식 결과, 직접 추가한 단어는 기기에서만 처리한다. OCR은 이미지 사본이나 접근 권한을 보관하지 않는다.

AI 사용량

성공과 실패 횟수, 글자 수만 기록한다. 원문, 결과, 키, URL은 사용량 기록에 남기지 않는다.

사용자가 시작하는 외부 전송

전체 오프라인 모드는 아래 네트워크 기능을 한 번에 차단한다. 전송은 HTTPS 또는 WSS만 허용한다.

온라인 공급자는 연결 IP 같은 네트워크 정보를 받고, 이를 이용해 대략적 위치를 추론할 수 있다.

글쓰기 AI

화면에 표시한 원문, 직접 요청, 동작 지시를 설정한 AI 공급자에 보낸다. 본문과 수신자를 확인하고 작업 버튼을 누른 경우에만 전송하며 store=false를 요청한다.

내 컴퓨터 연결을 쓰면 본문은 승인한 Tailscale HTTPS 연결을 거쳐 로그인된 Codex 또는 Claude Code로 전달된다. CLI의 OAuth 토큰과 API 키는 Android로 복사하지 않는다.

온라인 음성

정밀 받아쓰기는 녹음이 끝난 뒤 메모리의 WAV를, 실시간 받아쓰기는 말하는 동안 PCM 조각을 설정한 음성 공급자에 보낸다. 회의 전사는 직접 고른 최대 24MB, 60분 파일만 전송한다.

첫 마이크 사용과 첫 파일 선택 전에 수신자, 목적, 전송 시점, 앱 비보관을 알리고 동의를 받는다. 앱은 녹음과 파일 사본을 보관하지 않는다.

GIF와 미디어

Animated Noto Emoji는 검색어를 기기에서 비교하고 목록과 미디어만 Google Fonts에서 받는다. 캐시는 최대 24시간 보관한다.

KLIPY, Wikimedia Commons, GIPHY를 선택하면 검색어와 미디어 요청을 해당 공급자에 보낸다. 승인된 GIPHY 구성은 임의 앱 식별자와 노출, 클릭, 전송 이벤트도 보내며 설정 삭제 시 식별자를 지운다.

OCR 모델

한국어 모델 받기를 누르면 고정된 모델 파일을 GitHub에서 내려받고 크기와 SHA-256을 확인한다. 이미지와 인식 결과는 보내지 않는다.

인증 정보

사용자가 입력한 API 키와 OAuth 상태는 Android Keystore로 암호화한 백업 제외 저장소에 둔다. 공급자를 삭제하거나 로그아웃하면 앱에 보관한 자격 증명을 삭제한다.

Google Play Data Safety

선택형 기능이라도 기기 밖으로 나가는 데이터는 보수적으로 수집과 공유에 포함한다.

대략적 위치공급자가 받는 IP 주소에서 추론될 수 있는 위치
앱 내 검색 기록네트워크 GIF 공급자에 보내는 검색어
기타 사용자 생성 콘텐츠AI에 직접 보내는 원문과 요청
음성 또는 소리 녹음받아쓰기 음성과 선택한 회의 파일
앱 상호작용승인된 GIPHY의 노출, 클릭, 전송 이벤트
기기 또는 기타 ID승인된 GIPHY에서만 쓰는 임의 앱 식별자

store=false와 앱의 로컬 비보관만으로 외부 공급자의 처리를 일시적 처리라고 간주하지 않는다. 모든 데이터 유형은 선택 사항이며 앱 기능에 사용한다. GIPHY 식별자와 이벤트는 분석 목적도 포함한다.

보관, 삭제와 사용자 제어

기기 안의 기록은 설정에서 지우고, 외부 전송은 공급자 계정과 방침에서 관리한다.

클립보드
기능을 끄거나 개별 항목과 전체 기록을 삭제할 수 있다.
개인 단어장
사용자가 삭제할 때까지 보관한다.
GIF 캐시
최대 24시간 보관하며 앱 설정에서 바로 지울 수 있다.
AI, 음성, GIF 연결
공급자 삭제나 로그아웃으로 키, OAuth 상태, GIPHY 식별자를 삭제한다.
마이크와 네트워크
Android 설정에서 권한을 철회하고, 앱에서 전체 오프라인 모드를 켤 수 있다.

외부 공급자에 이미 전송된 데이터의 열람, 삭제, 보존은 사용자가 선택한 공급자의 계정과 방침을 따른다.

보안과 권한

네트워크 전송은 HTTPS 또는 WSS로 제한하고, Android의 인증 정보는 Keystore 기반 백업 제외 저장소에 둔다. INTERNET 권한은 선택형 온라인 기능에, RECORD_AUDIO 권한은 사용자가 시작한 음성 전사에 사용한다. 마이크 권한은 앱 안의 별도 고지와 동의 뒤에만 요청한다.

새글은 개발자 운영 광고, 사용자 추적 SDK, 분석 SDK, 자체 계정 시스템을 포함하지 않으며 아동을 주 대상으로 설계하지 않았다. 어떤 보안 조치도 절대적 안전을 보장하지는 않는다.

이 웹사이트

이 사이트는 분석 스크립트, 광고, 쿠키, 문의 폼을 사용하지 않는 정적 사이트다. GitHub Pages가 사이트를 제공하므로 접속 IP, User-Agent, 요청 기록은 GitHub가 자체 방침에 따라 처리할 수 있다. 이메일 링크를 누르면 사용자의 이메일 앱과 서비스가 동작한다.

변경과 문의

기능, 공급자, 법적 요구가 바뀌면 이 페이지의 날짜와 내용을 갱신한다. 중요한 변경은 앱 릴리스 고지에도 표시한다.
