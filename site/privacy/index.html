일반 타이핑은 기기 안에서 100% 로컬 처리되며, 외부 네트워크 연결은 사용자가 기능을 쓰거나 해당 화면(예: 내 언어 금고 대시보드의 광고)을 열 때만 일어납니다.

기기 내 100% 로컬 완결 한글 조합, 클립보드, OCR, 개인 단어장

일반 타이핑 원문과 사전 데이터는 개발자 서버로 전송되지 않으며, 이를 다루는 입력 경로는 광고·분석 SDK를 쓰지 않습니다. 앱에 든 광고 SDK(Google AdMob)는 내 언어 금고 대시보드와 테마 상점 화면에서만 씁니다.

사용자 직접 승인 시에만 전송 새글 AI 모델 받기, 온라인 음성, 네트워크 GIF

수신 대상과 전송 내용을 화면에서 먼저 확인하고, 사용자가 실행 버튼을 누른 작업에 한해서만 1회성으로 전송됩니다. 광고는 이와 달리 내 언어 금고 대시보드나 테마 상점 구매 창을 열 때 Google AdMob에 요청됩니다.

목차

처리자와 범위 기기 내 로컬 데이터 사용자 승인 외부 전송 Google Play Data Safety 보관 및 제어 권한 보안과 Keystore 웹사이트 방침 변경 및 문의처

처리자와 적용 범위

앱, 한글 플러그인, 이 웹사이트 전반에 걸쳐 동일한 데이터 보호 원칙을 적용합니다.

새글(Saegeul)의 개발자이자 개인정보 처리자는 Yun Chan입니다. 본 방침은 Android 애플리케이션 net.chanpaca.saegeul, 공식 한글 플러그인 net.chanpaca.saegeul.plugin.hangul, 그리고 공식 웹사이트 saegul.chanpaca.net에 적용됩니다.

일반 한글 입력은 기기 안에서만 처리됩니다.

키보드로 입력하는 일반 텍스트, 조합 중인 글자, 사전 검색어는 개발자 서버나 제3자 서버로 전송되지 않습니다.

기기 안에서만 처리하는 데이터

기능을 활성화하더라도 아래 데이터는 기기 밖으로 절대 수집되거나 전송되지 않습니다.

일반 타이핑 & 한글 조합

Fcitx5 및 libhangul C 엔진이 기기 내 메모리에서 직접 글자를 조합합니다. 비밀번호 및 민감 입력창에서는 텍스트 검사와 네트워크 기능을 원천 차단합니다.

클립보드 기록

새 설치 시 기본값은 꺼짐입니다. 켜더라도 기기 내 앱 전용 암호화 데이터베이스에만 저장되며, Android 클라우드 백업과 기기 이전 대상에서 제외됩니다. 사용자가 고른 클립보드 글을 바꾸는 스마트 클립보드도 기기 안에서만 처리하고, 바꾼 결과는 미리 보여 준 뒤 넣거나 취소할 뿐 따로 보관하지 않습니다.

온디바이스 OCR & 단어장

선택한 이미지와 텍스트 인식 결과, 사용자가 직접 등록한 개인 단어장은 기기 내에서만 처리되며 외부로 복사되지 않습니다.

새글 AI & 언어 금고

입력창 문맥, 앱 종류, 최근 보낸 문장, 개인정보를 가린 내 문장은 기기 안 Gemma 모델에만 넣고 앱이 밖으로 보내지 않습니다. 추천에 쓴 입력과 응답은 저장하지 않습니다. 배운 말투는 Android Keystore로 암호화하고 클라우드 백업에서 제외하며, 사용자가 직접 내보낼 때만 비밀번호로 암호화한 백업 파일을 만듭니다.

사용자가 직접 시작하는 외부 전송

사용자가 특정 버튼을 누르거나 해당 기능 화면을 열 때만 그 기능의 공급자와 종단간 암호화(HTTPS/WSS)로 통신합니다.

설정에서 '전체 오프라인 모드'를 켜면 앱이 여는 아래 네트워크 요청(새글 AI 모델·OCR 모델·문장팩 받기, 온라인 음성, 네트워크 GIF, 광고)을 막습니다.

새글 AI 모델 받기

사용자가 '새글 AI 설치하기'를 눌렀을 때만 Hugging Face에서 모델 파일(약 2.6GB)을 받습니다. 이때 연결 IP가 Hugging Face에 보이며, 입력한 글과 언어 금고는 보내지 않습니다. 와이파이가 기본이고 모바일 데이터는 따로 확인합니다.

온라인 음성

기본 '휴대폰 받아쓰기'는 로컬 변환이며, 사용자가 OpenAI STT 키를 직접 연결해 실시간/정밀 전사를 요청했을 때만 마이크 오디오 스트림이 해당 공급자로 전송됩니다. 녹음 원본은 파일 시스템에 저장되지 않습니다.

회의 파일 전사

파일 업로드 안내에 동의하고 시스템 파일 선택기에서 음성 파일(최대 24MB·60분)을 직접 골랐을 때만, 그 파일을 설정한 OpenAI 호환 음성 공급자에게 HTTPS로 보냅니다. 이때 연결 IP가 공급자에게 보입니다. 앱은 파일 사본을 보관하지 않으며, 선택이나 전사를 취소하거나 키를 지울 수 있습니다.

GIF 및 미디어

Animated Noto Emoji는 기기 내에서 키워드를 매칭합니다. 다만 GIF 도구를 열거나 미디어를 보여 줄 때 목록과 미디어를 Google Fonts에서 받아 오며, 이때 연결 IP는 보이지만 검색어는 보내지 않습니다. KLIPY, GIPHY, Wikimedia를 선택해 검색했을 때만 검색어가 해당 미디어 공급자에게 전송됩니다. GIPHY는 승인된 설정에서만 쓰며, 앱별 임의 식별자와 시각, 노출·클릭·전송 이벤트도 함께 보냅니다. GIF 캐시는 최대 24시간 보관합니다.

OCR 모델 받기

사용자가 '한국어 모델 받기'를 눌렀을 때만 GitHub raw content에서 고정된 OCR 모델 파일을 받습니다. 이때 연결 IP와 User-Agent가 보입니다. 검증된 모델 파일만 기기에 보관하며, 전체 오프라인 모드나 앱별 네트워크 정책으로 막을 수 있습니다.

선택 문장팩

설치 후 안내나 설정에서 사용자가 다운로드를 고를 때만 GitHub raw content에서 고정된 공개 예문 파일을 받습니다. 이때 연결 IP와 User-Agent가 보이며, 입력 문맥·개인 금고·인증 정보는 보내지 않습니다. 자동 다운로드나 원격 업데이트 조회는 없습니다. 받은 문장팩은 검증한 뒤 개인 금고와 분리해 백업 제외 저장소에 두고, 추가팩은 지울 수 있습니다. 소형 기본팩은 오프라인으로 제공됩니다.

AdMob 대시보드 배너

내 언어 금고(AI 언어 지문 대시보드) 화면을 열면 화면 아래쪽에 보여 줄 배너 광고를 Google AdMob에 자동으로 요청합니다. 횟수 제한은 없습니다. 이때 광고 ID와 App set ID, 연결 IP, 기기 정보, 광고 노출·클릭 이벤트, 앱과 SDK 성능 진단 정보(앱 실행 시간, 멈춤 비율, 에너지 사용 등)가 AdMob에 전송되고 광고 SDK 캐시가 남습니다. 앱은 입력한 글, 언어 금고, 키워드를 광고 요청에 넣지 않습니다. 언어 지문 삭제 확인 창이나 권한 요청 창이 떠 있는 동안에도 배너는 화면에 남아 있습니다. 이 배너는 전체 오프라인 모드로만 끌 수 있고, 광고 ID는 재설정할 수 있습니다.

AdMob 전면 광고

내 언어 금고 화면에서 「분석하고 LLM 강화」, 「언어 금고 보강」, 학습 카드의 「지금 반영하기」로 시작한 동기화가 끝난 뒤(안내 창이 있으면 닫은 뒤)에만 표시할 수 있습니다. 하루 1회, 24시간 간격이며 동기화를 3번 이상 한 뒤부터입니다. 이 조건을 만족하면 화면을 열 때 광고를 미리 받아 둡니다. 보내는 정보는 대시보드 배너와 같고, 앱 안에 노출·동기화 횟수 카운터를 둡니다. 전체 오프라인 모드로 막을 수 있고, 광고 ID를 재설정할 수 있습니다.

AdMob 보상형 광고(테마 상점)

테마 상점에서 가지지 않은 테마를 눌러 구매 창을 열면 보상형 광고를 미리 받아 두고, 「광고 보고 +1」을 누를 때만 보여 줍니다. 끝까지 보면 테마 포인트 1점을 모읍니다. 하루 3회, 20분 간격입니다. 보내는 정보는 대시보드 배너와 같고 보상 이벤트가 더해집니다. 포인트 원장과 보유 테마는 기기에 저장됩니다. 전체 오프라인 모드로 막을 수 있고, 광고 ID를 재설정할 수 있습니다.

인증 정보

사용자가 입력한 음성 전사·GIF 공급자 API 키는 Android Keystore 하드웨어 암호화로 보호되는 백업 제외 저장소에 저장됩니다. 공급자 삭제 시 즉시 완전 파기됩니다.

Google Play Data Safety

선택형 기능이라도 외부로 전송 가능한 데이터 항목을 투명하게 고지합니다.

대략적 위치네트워크 연결 시 공급자가 확인하는 IP 주소 기반 위치
앱 내 검색 기록네트워크 GIF 공급자 선택 시 전송되는 미디어 검색 키워드
음성 또는 소리 녹음온라인 음성 전사나 회의 파일 전사를 직접 실행했을 때의 음성 데이터
앱 상호작용승인된 GIPHY 구성을 사용할 때의 결과 노출, 클릭, 전송 이벤트와 Google AdMob 광고(대시보드 배너, 전면 광고, 테마 상점 보상형 광고)의 노출·클릭·보상 이벤트
기기 또는 기타 ID승인된 GIPHY 구성에서만 사용하는 앱별 임의 식별자와 Google AdMob 광고에 쓰이는 광고 ID·App set ID
진단Google AdMob SDK가 수집하는 앱과 SDK 성능 정보(앱 실행 시간, 멈춤 비율, 에너지 사용 등)

Google AdMob SDK가 받는 IP 주소, 광고 ID·App set ID, 광고 이벤트, 진단 정보는 광고와 사기 방지·보안·규정 준수 목적으로 수집·공유된다고 신고하며, 광고 ID·App set ID, 광고 이벤트, 진단 정보는 분석 목적도 함께 신고합니다. 이는 Google이 공개한 AdMob SDK 데이터 공개 기준을 따른 것입니다.

보관, 삭제 및 사용자 제어

기기 내 모든 데이터는 사용자가 언제든 즉시 열람하고 완전히 삭제할 수 있습니다.

클립보드 기록
앱 설정에서 개별 항목 삭제 또는 전체 기록 즉시 삭제가 가능합니다.
개인 단어장
사용자가 단어를 직접 삭제하거나 앱 데이터를 초기화할 때까지 로컬에만 보관됩니다.
음성 공급자
공급자 삭제 버튼을 누르면 Android Keystore에 저장된 API 키가 영구 파기됩니다.
권한 및 네트워크
Android 설정에서 마이크 권한을 철회하거나, 앱 내 '전체 오프라인 모드'를 활성화할 수 있습니다.

보안과 권한

모든 네트워크 전송은 HTTPS 또는 WSS 프로토콜로 강제되며, 인증 키는 Android Keystore 기반 비인가 접근 차단 저장소에 보관됩니다. Google AdMob 광고는 내 언어 금고 화면 하단 배너, 그 화면의 동기화가 끝난 뒤 표시할 수 있는 전면 광고, 테마 상점에서 사용자가 「광고 보고 +1」을 고를 때의 보상형 광고 세 곳에만 있으며, 키보드 입력 화면과 설정 첫 화면에는 광고가 없습니다.

이 웹사이트의 방침

본 웹사이트(saegul.chanpaca.net)는 쿠키, 추적 스크립트, 광고를 일절 사용하지 않는 순수 정적 웹페이지입니다. 사이트를 호스팅하는 GitHub Pages의 기본 접속 로그(IP, User-Agent)는 GitHub의 자체 개인정보 정책을 따릅니다.
